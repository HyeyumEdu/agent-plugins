# 시험지 HWPX 형식 지침

기준 시험지의 XML에서 뽑은 값과 사용자 지침이다. `scripts/build_exam.py`(JSON → HWPX)가 이대로 만들고 `scripts/verify_exam.py`가 검사한다.
단위: HWPX 길이는 1/100pt(`hwpunit`). 1pt = 100, 1mm ≈ 283.5. "pp/cp"는 템플릿 헤더의 `paraPr`/`charPr` ID. 규칙 ID(G·V)는 `scripts/verify_exam.py`의 검사 ID와 같다(V는 검사기가 V1·V5·V9만 확인한다).

**목차**: 1 공통 규칙 · 2 형식별 값 · 3 요소별 작성 규칙 · 4 띄어쓰기·글자 간격 · 5 문장 시작 줄 맞춤 · 6 미주 · 7 쪽·단 흐름 · 8 넣지 않은 것

## 3. 요소별 작성 규칙
**제목·안내문** — 제목은 첫 문단(쪽·단 설정 `secPr`+`colPr`이 든 문단이므로 지우지 않는다). 제목 다음 빈 문단 1개, 그다음 안내문. 안내문 문단 모양은 본문과 같다(양쪽, 160%, `KEEP_WORD`), 글자만 굵게.

**안내문과 지문 사이 빈 줄(3pt 고정)** — 안내문과 지문 사이에 빈 줄을 두면 그 빈 문단의 글자 크기는 **3pt**다(문단 모양은 본문 `pp0`이라 줄 간격 160%가 붙어 실제 한 줄 높이는 약 4.8pt: `vertsize 300`+`spacing 180`). `basic`은 문단 테두리 지문 앞에 3pt 빈 줄(`charPr 31`)을 **자동으로 넣는다**(JSON에 `blank`를 따로 적으면 자동 삽입은 하지 않고 적은 개수만큼 3pt 빈 줄이 된다).

**지문(문단 테두리, `basic`)** — 2절 V4. 출처줄은 오른쪽 정렬 문단에 `- 저자, 《책》(연도)`를 직접 입력한다(8~9pt).

**지문 글 규칙(G42~G47, 스크립트가 자동 처리하거나 어기면 오류·경고)**
- **안내문**: `※ 다음 글을 읽고 물음에 답하시오.` — `[1~3]` 같은 문제 번호 범위는 쓰지 않는다(G42). 빌더가 범위를 지우고 `※ `를 붙인다.
- **원문자 표시와 `:`**(G43): `㉮: 아름다움을…`처럼 표시 문자 바로 뒤에 `:`를 붙이고 `:` 뒤는 한 칸. 빌더가 `㉮ :`·`㉮:글` 을 고친다.
- **원문자 표시와 밑줄**(G44): 지문의 표시 문자(㉠~·ⓐ~·㉮~)는 밑줄 밖에 두고 **바로 뒤**에 가리키는 낱말·문장을 밑줄로 긋는다(JSON: `㉠<u>등대마다 다르다</u>`, 대사는 `ⓐ“<u>…”</u>`). 밑줄을 빠뜨리면 빌더가 오류로 알린다(범위는 글 내용으로만 정해져 자동으로 정할 수 없다). 밑줄 글자 모양은 같은 글자 모양에서 `underline type="BOTTOM" shape="SOLID" color="#000000"`만 바꾼 쌍둥이다(`basic` 본문 `cp0`↔`cp32`).
- **구분 표시**(G45·G46): `(가)`·`(나)` 머리 표시는 굵게(`(가)` 세 글자만, 뒤 공백은 굵지 않게). `(나)`~ 머리 문단 앞에는 빈 줄 정확히 1개(출처줄 `- 저자, 「제목」` 문단이 사이에 있어도 그 뒤에 1개). 첫 문단 앞에는 빈 줄이 없다.
- **줄거리 표시**(G46·G47): `(가) 앞부분 줄거리 | 요약…`처럼 같은 문단 안이면 `(가)`는 굵게(본문 크기), `[앞부분 줄거리] 요약…` 전체는 9pt. `…줄거리` 한 줄 문단이면 `[…줄거리]` 9pt, 바로 뒤 요약 문단 9pt, 요약 뒤에 빈 줄 1개. 라벨은 굵게 하지 않는다. 앞에도 빈 줄 1개. 낱말은 작성자가 쓴 그대로 둔다(`앞부분의 줄거리`·`중략 부분 줄거리` 등).
- **출처줄**: 지문 `paras`에서 `- `로 시작하는 문단은 오른쪽 정렬 출처줄이 된다(여러 묶음 `(가)`·`(나)`에 각자 출처줄을 둘 때).

**`<보기>` 상자(1×1, `basic`)** — 폭 20038, 테두리 0.25mm, 칸 여백 550/550/400/400, 세로 정렬 `TOP`, **글자처럼 취급**(`treatAsChar=1`, `horzRelTo=PARA`)이라 표를 담는 문단은 `pp53`이고 뒤에 빈 문단이 따로 들어가지 않는다(G39).

**발문(`basic`)** — 문단 pp62(번호 자동), 글자 굵게 cp37, 부정 낱말은 굵게+밑줄 run cp38. 발문 앞은 문단 위 간격 800.

**선택지** — 5개를 연속 문단으로, `①`+탭+본문으로 만든다. 문단 모양은 아래 원본 문단 모양의 복제본에 탭 정지 하나(`pos` = `left+abs(intent)`)를 더한 것이고, 탭 `width`는 `탭 정지 − left − 원문자 폭`(한컴이 열 때 다시 계산하는 참고값)이다. `basic`: pp41(`left` 500, `intent` −1488), 탭 정지 1988, `width` 519. 글(복사·추출)로 읽으면 `① 본문`과 같다. 복제본은 쪽 나눔 설정도 바꾼다: ①~④ `keepWithNext=1`, ⑤ `0`, 모두 `keepLines=1`(G40).

### 4.2 글에서 띄어 쓰는 방법
- **낱말 사이 1칸, 문장 사이 1칸.** 마침표·물음표·닫는 따옴표 뒤 공백은 1칸.
- **선택지**: `①`+탭+본문(G49), 끝 공백 없음, 끝 마침표는 G20.
- **발문**: `…것은?`. 배점은 `?` 뒤 공백 1칸 + `[3.6점]`(괄호 안 공백 없음). 미주 호출은 마지막 글자(`?` 또는 `]`) 바로 뒤, 공백 없음. `윗글`은 붙여 쓰고, `<보기>의`·`〈보기〉의`·`㉠~㉤을`처럼 조사는 붙인다.
- **표시 기호**(`㉠~㉤`, `ⓐ~ⓔ`, `㉮㉯`): 앞 낱말과 띄우고 뒤는 붙인다(`㉠에`, `ⓑ“한국은`). 지문 위치 `[A]`도 같다. 이 규칙은 지문·발문에 해당한다.
- **안내문**: `※`+공백 1칸.
- **출처줄**: `- `(하이픈+공백) + `저자 외, 《책 제목 1》(2020)` — 쉼표 뒤 1칸, `》`와 `(`는 붙임, 오른쪽 정렬.
- **`<보기>` 표시(`basic`)**: 상자 라벨은 `〈 보 기 〉`(글자 사이 1칸), 발문 속에서 가리킬 때는 `〈보기〉`(붙임).
- **지문 문단 첫머리(`basic`)**: 공백 문자 1칸으로 들여쓴다(스크립트가 붙인다). 소제목 문단은 들여쓰지 않는다.
- **미주 라벨(`basic`)**: `정답 ⑤`+공백 3칸+`[3.6점]`, `출제 포인트`+공백 2칸+본문, `정답 해설`+공백 2칸+본문. 미주 첫 문단은 자동번호 뒤 공백 1칸.

### 4.3 선택지 한 글자 넘침과 자간 줄이기
선택지의 마지막 줄에 **한 글자(+마침표나 물음표)만** 남으면(`다.`, `가?` 등) 모양이 어색하다. 스크립트가 그 선택지의 자간만 −1~−7%로 줄여 한 줄 덜 쓰게 한다.
- **판정**: `build_exam.py`가 선택지 글을 글자 단위로 줄바꿈해 보고, 마지막 줄이 한 글자(마침표·물음표·쉼표 뺀 글자 수 1 이하)이면 넘친 것으로 본다. 선택지가 한 줄이거나 마지막 줄이 두 글자 이상이면 건드리지 않는다.
- **조치**: 그 선택지만 글자 모양(`charPr`)을 복제해 자간을 −1%부터 −7%까지 1%씩 줄여 보고, 한 줄이 줄어드는 가장 작은 값을 쓴다(템플릿 헤더에 글자 모양이 더해진다). −7%로도 안 되면 경고하고 그대로 두니 문구를 줄인다. 요약 줄에 `자간 줄임: 문항 2-③ -3%`처럼 알린다.
- **자간 의미**: 글자마다 글자 크기의 n%만큼 폭이 줄어든다(10pt 글자에 −5%면 글자당 0.5pt). 한글·영문·숫자·공백 모두 같은 값(`spacing`의 7개 속성)으로 쓴다. 장평은 100% 그대로.
- **줄바꿈 예측 모델**: 글자 폭(em, 함초롬바탕 장평 100%·자간 0)은 **한글·한자·원문자 0.9689**, 공백 0.5, 그 밖의 글자는 글자별 값(숫자·`?`·`~` 0.55, `. , : ; ! ( ) [ ] ‘ ’` 0.32, `“ ”` 0.48, 영문은 글자마다 0.287~0.91)이다. 번호 뒤를 탭으로 띄우므로 본문이 모든 줄에서 탭 정지부터 시작해 **모든 줄의 폭이 같다**: 본문 줄 폭 = 단 폭 201.24pt − `left` − `abs(intent)`, `basic` 181.36pt(보정 −0.5pt). 줄 끝에 닿은 공백은 폭에 세지 않고, `. , ? ! ) ] ’ ” 」` 등은 줄머리에 올 수 없어 앞 글자와 함께 내려간다.
- **한계**: 영문·기호가 많은 선택지는 글자 폭이 달라 틀릴 수 있다(예측이 틀리면 한글에서 한 번 보고 자간을 직접 고친다). 영문 단어는 한컴이 낱말 단위로 줄바꿈하는데 모델은 글자 단위로 끊어 영문이 많은 선택지는 달라질 수 있다. 자간을 줄인 뒤 줄이 들어가는지는 본문 폭을 2pt(`SAFE`) 좁게 잡고 확인한다. 느낌표·물음표 뒤 마침표(`!.`·`?.`)는 뺀다. 마지막 줄이 `가’.`·`가).`처럼 한 글자+닫는 따옴표·괄호+마침표여도 넘침으로 본다. 지문·발문·보기·해설의 한 글자 넘침은 다루지 않는다.

## 5. 문장 시작 줄 맞춤
**읽는 법**: `intent`가 음수(내어쓰기)이면 **첫 줄은 `left`에서 시작하고 둘째 줄부터 `left+abs(intent)`에서 시작**한다. 양수(들여쓰기)이면 첫 줄만 `left+intent`에서 시작하고 나머지는 `left`.

| 요소 | `left` / `intent` | 첫 줄 시작 | 둘째 줄부터 |
|---|---|---|---|
| 본문 지문 | 0 / 0, 양쪽 | 단(또는 상자) 왼쪽 | 같음 |
| 발문 | 0 / 0 + 자동 번호(`autoIndent=1`, `textOffset=50%`) | 번호가 단 왼쪽(0pt)에서 시작, 번호 뒤 본문은 약 16pt | **번호 뒤 본문 시작 위치(약 16pt)에 맞춰짐** |
| 선택지(`basic`) | 500 / −1488 (10pt) | 5.0pt | 19.88pt |
| `<보기>` 안 문단(`basic`, 시) | 0 / **+1054**(pp85), 줄간격 125% | 한 글자 폭 안쪽 | 0pt |
| `<보기>` 안 문단(`basic`, 산문) | 0 / 0(pp55), 첫머리 공백 1칸으로 들여씀 | 단 안쪽 | 같음 |
| 제목(`basic`) | 0 / 0, **가운데 정렬**, `BREAK_WORD` | | |
| 미주 선택지 해설(`basic`) | 1500 / −1300 | 15pt | 28pt |
| 출처줄 | 대체로 0 / 0, **오른쪽 정렬**, `BREAK_WORD` | 오른쪽 끝에 붙음 | |

- 선택지의 `abs(intent)`는 `①`+공백의 폭으로 둔다, `basic` −1488(10pt 함초롬바탕에서 14.88pt).

### 5.1 선택지 번호 뒤 본문 시작 위치
**번호와 본문 사이를 공백이 아니라 탭으로 띄우고 탭 정지를 둘째 줄 시작(`left+abs(intent)`)에 둔다.** 공백으로 띄우면 양쪽 정렬이 첫 줄의 낱말 사이 공백(번호 뒤 공백 포함)을 선택지마다 다르게 늘려 번호 뒤 본문 시작이 어긋나고, 둘째 줄 시작도 `①`+공백의 자연 폭과 달라 첫 줄 본문과 맞지 않는다. 탭 폭은 양쪽 정렬로 늘어나지 않고 탭 정지까지만 가므로 모든 선택지의 첫 줄 본문 시작이 같고 둘째 줄 시작과 같다. 번호~본문 간격은 탭 정지까지의 거리다, `basic` 5.16pt. 헤더에 탭 정의(`tabPr`) 하나가 더해진다. 탭 문자는 선택지를 복사하면 남는다.

## 7. 쪽·단 흐름
- 기준 시험지는 `columnBreak`·`pageBreak`를 쓰지 않고 **빈 문단으로 다음 단·쪽까지 밀어낸다**. 문서 끝은 `정답과 해설` 제목 문단 자체가 새 쪽을 연다(`pageBreak="1"`, 6절) — 끝에 `page_break`를 따로 둘 필요가 없다.
- `build_exam.py`는 기준 시험지 방식의 `blank` 말고도 `column_break`·`page_break` 항목을 지원한다(`hp:p`의 `columnBreak="1"`·`pageBreak="1"`을 다음 문단에 붙인다. `items` 맨 끝의 `page_break`는 `정답과 해설` 제목 문단이 받는다). 렌더 확인 수단이 없어 `blank` 개수를 못 맞출 때 쓰며 지침 이탈이라 `verify_exam.py`가 G6을 경고(WARN)로 알린다.
- `column_break`·`page_break`를 쓰면 빌드가 쪽·단 구간마다 높이를 어림해(`nlines`: 평균 글자 폭 0.85em으로 줄 수를 세고, 줄 높이는 발문·선택지 한 줄, `basic` 12.5pt·지문 16pt) 쪽별로 보여 준다. 단 나눔이 없는 쪽은 두 단(1315pt)에 걸쳐 흐르는 것으로, 단 나눔이 하나인 쪽은 각 단이 한 단(658pt) 안에 들어가야 하는 것으로 보고 넘치면 경고한다. 어림 오차는 ±10% 정도라 90% 이상이면 여유가 없다고 본다.
- 한 단의 본문 높이는 65761(657.6pt)이다(용지 84186 − 위 5669·머리말 4252 − 아래 4252·꼬리말 4252). 빈 문단 하나는 약 16pt다. `basic`은 선택지·발문 한 줄이 12.5pt(10pt×125%)라 한 단에 약 52줄이다.
- 빈 문단 수는 내용 길이에 따라 달라진다. 내용을 바꾸면 렌더해서 다시 센다.
- 한 문항(발문+선택지)과 `<보기>`는 같은 단에 두고, 새 글감 묶음은 단 머리에서 시작한다.

### 7.1 문항이 끊기지 않게 · 지문 묶음의 시작 위치
- **문항 보호(G40)**: 발문·〈보기〉 문단·선택지 ①~④에 `keepWithNext=1`, ⑤는 `0`, 글 문단은 `keepLines=1`인 문단 모양 복제본을 쓴다. 한컴이 조판할 때 문항을 통째로 다음 단(쪽)으로 보내며 높이 어림이 필요 없다. 사슬이 한 단보다 길면 지킬 수 없다.
- **블록을 통째로 지키는 비용**: 보기 문항을 지키면 단 아래가 최대 약 72%까지 빈다. 보기 표는 글자처럼 취급(G39)이라 쪽 끝에 안 맞으면 통째로 다음 단으로 간다.
- **지문 묶음 시작(G41)**: 첫 묶음(제목 아래)만 빼고 지문 묶음은 단 맨 위에서 시작한다. 안내문 문단에 `columnBreak="1"`을 붙인다(기본). `group_start: "page"`는 새 쪽 맨 위(`pageBreak="1"`, 왼쪽 단에서 끝난 묶음 뒤 오른쪽 단 전체가 빈다), `"flow"`는 나눔 없음. G6(강제 나눔)은 안내문·`정답과 해설` 문단의 나눔을 세지 않는다. 안내문과 3pt 빈 줄도 `keepWithNext=1`이다.

## 8. 넣지 않은 것
- 어휘·용어 풀이 문단, 왼쪽 막대 인용 상자, 도표(중첩 표), 그림, [A] 구간 표시용 3×3 표, 수식(`hp:equation`): 문항·글감 고유 요소라 만들지 않는다.
- 머리말·꼬리말·쪽번호: 넣지 않는다.
- `--lenient`(한컴 원본 검사)는 원본에 없는 사용자 지침 규칙을 건너뛰거나 느슨하게 본다: G20 비문장 마침표, G23(95%), G35(13~14pt, 없어도 됨), G36(선택지만), G39(개수만), G40~G42, G44~G47, G49.
