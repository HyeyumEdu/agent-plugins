# 오답 코드와 문항 유형 코드

기출·학교 시험의 오답 선지를 해부해 붙이는 코드와, 문항을 분류하는 코드다. 출제할 때는 오답 설계표에, 분석할 때는 코딩표에 쓴다. 새 유형을 발견하면 코드를 이어 붙인다(예: A9). 기존 코드와 겹치면 합친다.

## 오답 코드
<!-- 단계: 전체 -->
오답 선지마다 **대분류 + 번호**를 1~2개 단다. 원칙은 '오류 지점은 한 곳'이므로 두 곳 이상 틀린 선지는 따로 표시한다.

| A4 | 평가어 하나 뒤집기 | 자긍심 → '겸양의 태도' |

## 문항 유형 코드
<!-- 단계: 전체 -->
학교 시험지를 분석하거나 회차를 설계할 때 문항마다 붙인다. 오답 코드(A~J)와 헷갈리지 않게 다른 글자를 쓴다.

- **기본형 T**: T1 표현상·서술상 특징 / T2 내용 일치·이해 / T3 ㉠~㉤ 기호 의미·기능 / T4 [A][B] 구간 비교 / T5 소재 기능 / T6 화자·인물 태도 / T7 두 작품 공통점·차이점('모두/달리') / T8 시상 전개·구성 / T9 어휘(뜻풀이·사전적·문맥적 의미) / T10 내용 전개 방식(비문학)
- **〈보기〉형 V**: V1 외적 준거 감상(갈래론·작가론·시대 배경) / V2 이론 글 〈보기〉(관점론, 심리학, 꿈 이론, 인간형 분류, 자본 개념) / V3 외부 작품 〈보기〉 / V4 이중 〈보기〉 / V5 교사 설명·학습 활동지 / V6 도식·표(속성 표, 관점 도식, 수용론 도식) / V7 비평문 (가) + 작품 / V8 게시판 Q&A·누리집 답변
- **조합·판단형 M**(고배점이 많다): M1 있는 대로 고르기 / M2 개수형 / M3 짝짓기 / M4 분류형 / M5 O/X 표·진위 판단 표 / M6 표 빈칸 채우기 / M7 학생 갑~무 발언 있는 대로 / M8 영상화·연출 계획 대화 / M9 사건 순서 배열 / M10 조건 다중 충족(〈조건〉 4개로 문장 만들기)
- **창작·재구성형 R**: R1 연출 계획 / R2 시나리오 제작 노트 / R3 집필 구상 역추적 / R4 영상시 제작 계획 / R5 수정형·예문 생성형 / R6 패러디 원작 대비
- **문법형 L**: L1 개념 지문 → 적용 / L2 조항 원문 적용(단서·'다만') / L3 음운 변동 횟수·순서·개수 직접 세기 / L4 체계표 적용 / L5 형태소·단어 개수, 단어 형성, 직접 구성 성분 / L6 문장 성분·자릿수·문형 / L7 중세 국어 원문 + 현대어 풀이 / L8 순서도(예/아니요) / L9 '~가 다른 하나는?' / L10 잘못된 발음의 원인 표
- **화법·작문형 W**: W1 말하기 방식·전략(전략 이름 + 효과) / W2 청중 반응·질문 / W3 발화 연결 추적 / W4 이론 + 적용 / W5 자료 활용 / W6 고쳐쓰기 / W7 담화 응집성·응결성·지시·대용
