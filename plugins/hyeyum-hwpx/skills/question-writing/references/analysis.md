# 시험지·기출 분석 지침

학교 시험지(사진·PDF·한글·워드)나 수능·모평·학평 기출을 분석해 다음 출제에 반영할 때 적용한다. 오답 코드와 문항 유형 코드는 `guide.py 오답코드`(이 분류를 부르면 함께 나온다).

## 원칙
<!-- 단계: 전체 -->
1. **분석 대상은 '어떻게 묻는가'다.** 작품·범위 적중은 부차적이다. 대비 자료가 빗나가는 곳은 언제나 유형(이론 〈보기〉, 짝짓기, 영상화 대화, 어휘, 서술 방식 반복, 외부 작품 〈보기〉)이었다.
2. **선지를 풀지 말고 해부한다.** 오답 선지마다 *어느 단어를 무엇으로 바꿨는지* 찾아 '원문 → 바뀐 말'로 적는다. 정답 선지가 오답처럼 보이게 만든 장치도 적는다.
3. **정답은 스스로 풀어 확정한다.** 시험지의 학생 표시는 풀이 흔적이나 채점 표시일 뿐 정답지가 아니다.
4. **수치로 확인한다.** 느낌이 아니라 선지 길이·인용 수·연결어·발문 비율·정답 분포를 실제로 센다(평균이 아니라 중앙값).
5. **학교마다 따로 기록하고, 공통점은 따로 모은다.** 한 학교에서 얻은 유형은 다른 학교 출제에도 반영한다. 최신 시험지를 우선한다.
6. **분석은 출제 지시로 끝낸다.** 결과는 학교 프로파일과 '다음 출제 반영 지시'로 정리한다.

## 절차

| 단계 | 할 일 | 산출물 |
|---|---|---|
| 1 자료 확인 | 쪽 수·문항 수·누락 쪽·잘린 부분 확인 | 판독 메모 |
| 2 판독·복원 | 지문·발문·선지·〈보기〉·배점을 텍스트로 옮김 | 복원 원문 |
| 3 정답 확정 | 직접 풀기 → 학생 표시·점수와 대조 | 정답표 + 확인 필요 문항 |
| 4 형식 기록 | 시험 형식표 | 형식표 |

| 6 선지 분석 | 선지 문체 측정 | 선지 스타일 요약 |
| 7 오답 분석 | 오답 선지마다 오류 지점과 코드, 빈도 상위 5 | 오답 빈도표 |
| 8 난도 분석 | 학생이 실제로 틀린 문항의 원인 | 난도 요인 |
| 9 적중 대조 | 대비 자료와 비교(맞힌 것 / 빗나간 것 / 과잉 대비) | 적중 보고 |
| 10 반영 | 학교 프로파일 갱신 + 다음 출제 지시 | 프로파일 파일 |

## 판독과 복원
<!-- 단계: 전체 -->
- **쪽 수 대조**: 시험지의 '총 ( )면'과 받은 사진 수를 맞춘다. 빠진 쪽이 있으면 바로 알린다.
- 사진이 잘린 부분(가장자리, 손가락에 가린 글자, 하단 선지)은 위치를 적고, 추정한 부분은 '추정'으로 표시한다.
- 그림·도표·표는 무엇이 그려져 있는지 글로 기록한다.
- 학생 손글씨(체계표 칸의 글자, 여백 계산)는 복원본에 넣지 않는다.
- 파일 읽기: PDF는 텍스트를 뽑되 2단 편집은 단 순서가 섞이니 쪽 이미지와 대조한다. 앞쪽은 이미지·뒤쪽은 텍스트인 혼합본은 쪽별 글자 수로 구분한다. 한글(.hwpx) 시험지는 exam-basic 스킬의 `extract_hwpx_text.py`나 편집 도구의 읽기 기능으로 글을 뽑는다(도형·글상자 안 글은 빠질 수 있으니 개수를 확인해 알린다).
- 문항·선지·정답을 표(번호, 발문, 선지 5, 정답, 배점)로 정리해 두면 계량과 변형 출제에 바로 쓸 수 있다. 시험지 파일로 복원할 때는 exam-basic 스킬의 JSON 형식으로 옮긴다.
- 복원 파일에서 서식 제약으로 바꾼 것(표 → 줄글, 〈자료〉 → 〈보기〉, 단서를 〈보기〉 끝으로, 그림 → 글 설명 + 그림 자리, 서·논술형 처리)은 모두 알린다.

## 정답 확정
<!-- 단계: 전체 -->
1. **모든 문항을 직접 푼다.** 지문 근거 구절을 찾아 판정한다. 학생 표시나 정답표가 있으면 보기 전에 풀도록 `guide.py 검증,가림`의 순서(정답을 가린 묶음 → 풀이 → 대조)를 따른다.
2. 학생 표시와 대조한다. 일치하면 확정, 불일치하면 다시 푼다.
3. **점수로 역산한다.** 시험지에 점수가 적혀 있으면, 틀린 것으로 보이는 문항들의 배점 합이 그 점수와 맞는지 계산한다(예: 선택형 80점 중 세 문항 12.5점 감점 → 67.5 + 논술형 20 = 87.5). 맞으면 그 문항들의 학생 선택은 오답이고 정답은 다른 번호다.
4. 그래도 두 선지가 모두 맞아 보이거나 판단이 갈리면 **'학교 정답 확인 필요'** 로 표시하고 이유를 쓴다.
5. 문항 오류(정답 없음, 복수 정답, 인쇄 오류, 비표준 발음 표기, 거의 같은 선지)도 따로 기록한다. 그 학교가 어디서 오류를 내는지도 출제 경향이고, 우리 문항의 위험 패턴(`guide.py 공통 검수`)에 더할 거리다.

## 시험 형식표
<!-- 단계: 전체 -->
```
학교·학년·과목:              교과서(출판사·저자):
시행: 학년도 학기 차(날짜)     쪽 수:
선택형: __문항 __점 (배점 __~__, 단위 0.1)
서·논술형: __문항 __점 (소문항 배점: )
영역 구성: 문학 __ / 독서 __ / 화법 __ / 작문 __ / 문법 __ (문항 수·배점 합)
세트 구성: [1~3] 작품명 …  (세트당 작품 수, 외부 작품 위치)
발문: 긍정 __ / 부정 __ (비율 %)
조합형(있는 대로·개수형·짝짓기) 문항 수: __
정답 분포: ① __ ② __ ③ __ ④ __ ⑤ __
최고 배점 문항의 유형:        최저 배점 문항의 유형:
교과서 외 지문(범위 밖·연계 교재):
특이 사항(단서 조항, 문항 오류, 인쇄 오류):
```
- 배점 폭이 좁은 학교(예: 2.9~3.3)와 넓은 학교(2.8~4.9)를 구분한다.
- 서·논술형이 세트 안에 표기되는지('[9~14, 논술형 1]'), 따로 있는지 적는다.
- 함께 볼 것: 유형이 몇 가지 섞였는가, 외부 작품의 위치(지문 / 〈보기〉 / 선지 안), 지문 없이 〈보기〉만으로 푸는 문항, 범위 밖 지문.

코딩표(문항마다 한 줄)

| 번호 | 배점 | 발문(긍/부) | 문항 유형 코드 | 〈보기〉 유형 | 대상(작품·구간·기호) | 정답 | 오답 코드 | 비고 |
|---|---|---|---|---|---|---|---|---|

## 선지 스타일 측정
<!-- 단계: 전체 -->
| 항목 | 측정 |
|---|---|
| 선지 길이 | 문항 유형별 중앙값·범위(자) |
| 인용 수 | 작은따옴표 인용 개수 |
| 문형 틀 | 대표 문형 3~4개 수집 |
| 기호 문항 형식 | 콜론형('㉢: ~') 여부 |
| 〈보기〉 감상 말투 | '~하는군 / ~있어 / ~겠군' |
| 수사법 표기 | 명칭 vs 정의 풀이 |
| 개념어 밀도 | 선지당 개념어 수 |
| 조건 겹침 | 한 선지 안 판단 조건 수 |
| 구성 요소 | 인용 + 기능 + 효과 결합 여부 |
| 두 작품 진술 | 한 문장에 두 작품을 각각 진술하는가 |
| 화자 관점 가정 | '~로 볼 경우' 선지 |

- 함께 기록: 정답 선지가 무난한 문장인가 개념어가 화려한가, 오답이 분명한가(난도 중하) 한 지점만 미세하게 틀린가(고난도), 영역별 문체 차이.
- 시험지를 exam-basic JSON으로 옮겼으면 `check_items.py --school`로 정답 길이 순위·쉼표·발문 비율·정답 분포를 한 번에 센다.

## 기출 분석
<!-- 단계: 전체 -->
- 수능·모평·학평·수능 예시문항·연계 교재는 정답표를 확보한 뒤 분석한다. 먼저 모든 문항을 풀고 근거 구절을 적은 다음 정답표와 대조한다.
- 오답 선지마다 틀린 단어·구절과 원래 맞는 말을 적고(원문 → 바뀐 말) 코드를 단다.
- **정답이 숨는 방식**을 기록한다: 같은 틀·같은 길이·어휘 한 개 차이, 통사적 쌍둥이, 방패 선지, 〈보기〉 논점 배분, 과잉 해석처럼 보이는 맞는 선지, 정답이 길어도 분포는 균등.
  - 기록 형식: `정답 ④ — 은폐 장치: 통사적 쌍둥이(③과 목적어만 다름) / 방패: ⑤도 두 작품 묶음`
- 계량 항목: 선지 길이 중앙값과 사분위, 정답의 길이 순위 분포, 정답 길이 − 오답 평균, 인용·쉼표·문장 수, 연결어 빈도('하여', '을/를 통해', '(으)로써', '라는 점에서' …), 다섯 어미 일치 비율, 발문 비율, 정답 번호 분포, [3점] 위치, 한 문항 최장−최단.
- 문항마다 **한 줄 출제 포인트**로 끝낸다: "무엇을 묻는가 / 어떤 함정인가(코드) / 다음에 어떻게 쓸 것인가".

```
[회차] [번호] [영역]  출제 포인트
9모 8 독서   〈보기〉 정의('대표적 구성원')를 '전체'로 바꿔치기(G3·C2) → 정의어 한 단어 교체를 다음 세트에
9모 13 독서  원리를 극단 조건까지 늘림(C8) → 과학·기술 〈보기〉에 경계 조건 하나 추가
```

- 회차 분석 카드: 구성(영역별 세트·문항 수, [3점] 위치), 발문 비율, 정답 분포, 새로 발견한 오답 유형(코드 신설 여부), 코드 빈도 상위 5, 정답 은폐 장치, 계량 요약, 문항별 출제 포인트, 다음 출제 반영 지시. 최근 회차에서 늘어난 코드를 다음 변형 세트에 먼저 배치한다.

## 난도 요인과 학생 오답
<!-- 단계: 전체 -->
- 학생이 **실제로 고른 오답**은 '실제로 먹히는 함정'의 가장 확실한 증거다. 채점 표시와 점수 역산으로 틀린 문항을 확정하고, 가능하면 학생에게 왜 그 선지를 골랐는지 한 줄씩 받는다.
- 기록 양식(학생 이름은 적지 않는다)

| 시험 | 번호 | 정답 | 학생 선택 | 고른 선지 요지 | 함정 코드 | 왜 끌렸나 |
|---|---|---|---|---|---|---|

- 원인 분류: 개념어가 화려한 오답 / 시어 10여 개 묶은 유사·대립 판단 / 세부 문구 내용 일치 / 긴 대화·시나리오의 발화 주체 추적 / 세트당 작품 3~5편 + 외부 〈보기〉 / 한문·향찰 원문 / 갈래 지식 / 낯선 이론 개념 / 문법 다단계 판단·음운 개수 계산 / 짝 선지 한쪽만 틀림.
- 학생이 "어려웠다/쉬웠다"고 한 평가도 적는다.
- 학원 모의고사 결과도 같은 양식으로 모은다(선지별 선택률). 기록이 쌓이면 오답 코드별 '선택률 순위'를 만들어 잘 먹히는 함정을 먼저 쓴다.

## 분석을 마칠 때 점검
<!-- 단계: 전체 -->
- [ ] 모든 오답 선지에 오류 지점(원문 → 바뀐 말)과 코드를 달았는가
- [ ] 정답 선지의 은폐 장치를 기록했는가
- [ ] 정답표와 내 풀이가 다른 문항을 다시 확인했는가(문항 오류 가능성 포함)
- [ ] 계량 항목을 실제로 셌는가(중앙값 기준)
- [ ] 새 유형을 코드표에 더했는가
- [ ] 문항별 출제 포인트를 한 줄씩 썼는가
- [ ] 다음 출제 반영 지시를 구체적으로 적었는가
