# 풀이자 지침

정답을 모르는 상태에서 국어 시험 문항을 푸는 사람을 위한 지침이다. 받은 문항 파일만 읽고, 정답·해설이 든 파일(`정답표.json`, 원본 시험지, 다른 세트 파일)은 열지 않는다. 목표는 정답을 맞히는 것이 아니라 **선지마다 지문 근거로 참·거짓을 가려 적는 것**이다. 그래야 복수 정답·정답 없음이 드러난다.

## 문항 푸는 법
<!-- 단계: 전체 -->
1. 지문과 〈보기〉를 끝까지 읽는다. 시의 연·행, 소설의 장면 순서, 기호(㉠~㉤, ⓐ~ⓔ, [A][B])의 위치를 확인한다.
2. 발문의 조건을 적는다: 긍정('적절한 것')인지 부정('적절하지 않은 것')인지, 범위(㉠~㉤ 중 무엇), 단서 조항, '모두'·'달리'·'각각'·'만'.
3. 선지 다섯 개를 **하나씩 따로** 판정한다. 다른 선지와 비교해서 고르지 않는다.
   - 참: 지문·〈보기〉의 구절로 뒷받침된다.
   - 거짓: 어느 낱말이 지문의 무엇과 어긋나는지 짚을 수 있다.
   - 애매: 해석에 따라 참도 거짓도 될 수 있거나, 근거가 지문 밖(배경지식·그림)에 있다.
   - 근거는 배경지식이나 출제 의도 짐작이 아니라 지문·〈보기〉 안에서만 찾는다.
4. 답을 정한다: 부정 발문이면 거짓인 선지, 긍정 발문이면 참인 선지. '~가 다른 하나는?'처럼 하나를 골라내는 발문은 골라낼 선지를 거짓, 나머지를 참으로 적는다. 그런 선지가 둘 이상이거나 없으면 억지로 하나를 고르지 말고 그대로 적는다(`답`은 가장 유력한 것, 없으면 `null`).
5. 주의할 곳
   - 'A는 B와 달리': A에 있고 B에 없는지 **둘 다** 확인한다. B를 처음부터 끝까지 훑는다.
   - 조합형(ㄱ~ㅁ): 진술을 하나씩 참·거짓으로 정한 뒤 맞는 조합의 선지를 찾는다.
   - 앞 절은 참인데 뒤 절(해석·평가·효과)만 틀린 선지가 많다. 끝까지 읽는다.
   - 부사·한정어 하나('이미', '반복적으로', '혼자', '모두'), 주체·시제·방향이 바뀐 곳을 본다.
   - 계산·수치는 직접 다시 계산한다. 문법은 판정 기준(받았으면 `guide.py 문법 검수 --only`)으로만 판정한다.

## 결과 형식
<!-- 단계: 전체 -->
결과는 아래 JSON으로 지시받은 경로에 저장한다. `선지`는 ①~⑤ 순서의 "참"·"거짓"·"애매" 다섯 개, `답`은 1~5 또는 null, `확신`은 "높음"·"중간"·"낮음".

```json
{
  "풀이자": "A",
  "문항": [
    {"번호": 1, "답": 3, "선지": ["참", "참", "거짓", "참", "참"], "확신": "높음",
     "근거": ["① '…' 첫 문단과 일치", "② …", "③ '사방으로 흩뜨려' — 지문은 '한 방향으로 모아'", "④ …", "⑤ …"],
     "메모": ""},
    {"번호": 2, "답": 4, "선지": ["거짓", "거짓", "애매", "참", "거짓"], "확신": "중간",
     "근거": ["…", "…", "③ '대신 정해' — 지문에 소리 장치와 간격의 관계가 없어 판단 근거 없음", "…", "…"],
     "메모": "③은 지문 밖 지식 없이 판정 불가"}
  ]
}
```
- `번호`는 문항 파일의 '### N번' 번호를 쓴다.
- `근거`는 선지마다 한 줄로, 지문 구절을 작은따옴표로 인용한다.
- 마지막 답에는 저장한 경로와 '애매'로 둔 선지 개수만 적는다(정답을 맞혔는지 묻거나 추측하지 않는다).
