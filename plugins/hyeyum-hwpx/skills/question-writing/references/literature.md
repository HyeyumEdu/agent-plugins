# 문학 출제 지침

공통 지침과 함께 적용한다. 내신 문학이면 학교 형식(`guide.py 학교`)이 우선한다.

## 세트 구성
<!-- 단계: 설계 -->
| 구성 | 문항 수 | 표준 배열 |
|---|---|---|
| 현대시 1편 | 3 | 표현상 특징 → ㉠~㉤ 시구 이해 → 〈보기〉 감상 |
| 현대시 2편 | 4 | 공통점·차이점 → (가) 시구 → (나) 시구·[A][B] → 〈보기〉 감상 [3점] |
| 갈래 복합 3편 | 6 | 표현상 특징 → 작품별 기호 → [A][B] → 소재 → 〈보기〉 → 통합 〈보기〉 [3점] |
| 고전·현대 소설 | 4 | 서술상 특징 → 내용 이해 → ㉠~㉢ 또는 [A][B] → 〈보기〉 감상 [3점] |
| 확장 세트 | 10 | 아래 배분 |

**10문항 확장 세트 배분 예**: ① 공통점 또는 서술상 특징 ② (가) 표현상 특징 ③ [A]·[B] 비교 ④ (가) 〈보기〉 감상 ⑤ (나) 서술상 특징 ⑥ ㉠~㉤ 기능·의미 ⑦ (나) 〈보기〉 감상 ⑧ 통합 〈보기〉 [3점] ⑨ 소재의 서사적 기능 ⑩ 이중 〈보기〉 [3점]

- 일반 순서: 작품 전체(표현·서술상 특징) → 각 작품 내용 → 부분(㉠~㉤, ⓐ~ⓔ, [A]·[B]) → 소재·인물 기능 → 공간 → 〈보기〉 학습 활동형 → 〈보기〉 작품론형 [3점].
- [A]·[B]는 **서술 대목**으로 잡는다. 대화를 잡으면 '서술상 특징'을 물을 수 없다. 대화는 말하기 방식을 물을 때만 잡는다.
- 소재 문항은 사실 확인이 아니라 **기능**을 묻는다("~하는 방편/매개/계기/경계가 되고 있다", 인용 0개, 한 줄).
- 소설 세트에는 서사 구조를 묻는 문항을 섞는다: 정보 층위, 발화 의도, 시간 순서, 인물의 억측 정밀 독해, '나'의 대답과 침묵 분포.
- 갈래 복합 세트는 축이 같은 작품끼리 묶는다(예: '받쳐 주는 것', '그리움과 만남', '가난과 분수'). 한 세트에 최소 한 문항은 '모두/달리' 비교, 한 문항은 이중 〈보기〉 또는 외부 작품 〈보기〉.

## 다채로운 유형
<!-- 단계: 설계 -->
모의고사 틀에만 머물지 않는다. 세트마다 아래에서 **2~3개 이상**을 섞는다.

| 유형 | 예 |
|---|---|
| 연극·영상 각색 연출 계획 | 내적 독백을 곁의 인물이 듣게 연출하면 안 됨 |
| 낭송 계획 | 시의 어조·호흡에 맞는 낭송 방법 |
| 시어 여러 개 묶어 보기 | 시어 넷을 한 문항에서 유사·대립 판단 |
| 한자 성어 | 상황에 맞는 성어(오매불망 등) |
| 부호·반복 표현의 기능 | 말줄임표 여덟 번, 같은 후렴 두 번의 기능 |
| 제목의 의미 | 제목이 작품 안에서 갖는 뜻 |
| 표 제시형 두 작품 비교 | 두 작품의 '방'을 ㉮ 돌아오는 자리 / ㉯ 방 안의 상태 / ㉰ 방에서 하는 일로 비교 |
| 과장 대상의 차이 | [A] 벼룩 / [B] 쥐 / [C] 제 몸 |
| 인물 태도 변화 | 한 인물의 태도가 장면마다 바뀌는 지점 |
| 자기 정정 | "그 여자의 건강이 ― 아니 내 건강도" 고치는 과정이 속내를 드러냄 |
| 자리 이동 | [A] 창밖 → [B] 창 안쪽 |
| 공간 비교 | (가)의 공간과 (나)의 공간 |
| 같은 단어 지시 대상 구분 | '일' ㉠~㉢이 각각 무엇을 가리키는가 |
| 편지 발신·수신인 정리 | 편지 ㉠~㉢을 정리한 뒤 서사 기능 |
| 꿈과 현실의 경계 찾기 | 환몽 구조의 경계 대목 |
| 작품 간 상황 대응 | 한 작품의 상황 ↔ 다른 작품의 상황 ㉮~㉲ |
| 학생 감상문 ⓐ~ⓔ 판단 | 감상문 속 문장의 적절성 |
| 비평문 (가)의 개념으로 시 읽기 | 비평 개념을 작품에 적용 |
| 교과 융합 〈보기〉 | 사회 생태주의, 부르디외 자본 개념, 심리학 개념 |

## 선지 문형
<!-- 단계: 작성 -->
| 유형 | 문형 |
|---|---|
| 서술상 특징 | `~하여 ~하고 있다.` (인용 0개, 한 줄) |
| 기호 이해 | `㉠: ~하여 ~하고 있다.` / `㉠: ~한 것은, ~를 드러낸 것이겠군.` |
| 소재 | `~하는 방편/매개/계기가 되고 있다.` (인용 0개) |
| 〈보기〉 감상(시) | `'인용'은 ~라는 점을 보여 주는 것이겠군.` / `'인용'에서 ~을 엿볼 수 있군.` / `(가)는 ~라고 하여 ~를 드러내는군.` |
| 〈보기〉 감상(소설) | `인물이 ~하는 데(에)서, ~을 알 수 있군.` / `~하는 데에서, ~하려는 것을 확인할 수 있군.` |
| 〈보기〉 감상(수필·교술) | `~에 주목해 ~라는 인식을 드러내는군.` |
| 두 작품 비교 | `(가)는 ~하는 것과 달리, (나)는 ~하고 있다.` / `~하는 데 비해` / `~하는 반면` / `모두 ~하고 있다` / `~한 것처럼, ~도 ~하고 있다` |

- 구조: **지문 인용(앞 절, 항상 참) + 연결어 + 판단어(뒤 절)**.
- 비교형은 연결 어구를 2~3종으로 섞어 형식만 보고 정답을 찾을 수 없게 한다.
- 최근 〈보기〉 감상 문항은 시어 하나를 해석하는 데서 그치지 않고 **여러 시어·시구를 인용해 하나의 장면으로 재구성**하고 그 내용 일치를 묻는다.
- 고친 예
  - (전) 윗글의 '서기는 혼자 울고 있었다'와 〈보기〉의 '묵중하게 서 있었다'는, 모두 대상의 속을 알지 못한 채 겉으로 드러난 모습만을 옮겨 적은 자리이다.
  - (후) 윗글의 '서기는 혼자 울고 있었다'와 〈보기〉의 '묵중하게 서 있었다'는 모두 대상의 내면을 알지 못한 채 겉으로 드러난 모습만을 제시하고 있다.

| 유형 | 목표 길이(중앙값) |
|---|---|
| 작품 전체 특징 | 30자 안팎, 한 줄, 인용 없음 |
| 일반(내용·기호·소재) | 36~47자 |
| 〈보기〉 감상형 | 58~81자 |
| 두 작품 비교형 | 80~95자 |

## 오답 함정
<!-- 단계: 작성 -->
**기본**
| 유형 | 예 |
|---|---|
| 방향 역전 | "병이 없다고 한다" → '병이 있다고 말해 준다' |
| 수 조작 | '한 사내', '혼자' → '여러 사람이 남아 있는' |
| 주체 교체 | 물을 적셔 주는 쪽은 '그녀'인데 화자로 |
| 시제 교체 | 지금의 판단 ↔ 그날의 판단 |
| 사실 반대 | "처음으로"·"우연히" → '오래전부터 드나들던' |
| 행위 목적 바꾸기 | "침묵을 달아나지 못하게 하느라" → '울음을 멈추게 하려' |
| 없는 동기 부여 | 옷깃을 여미는 몸짓 → '화자의 시선을 의식하여' |
| 평가어 뒤집기 | 긍정 ↔ 부정, 자긍심 → 겸양 |
| 의성어·의태어 정서 뒤집기 | 놀라움 → 안타까움 |
| 공감각 전이 방향 뒤집기 | 시각의 후각화 → 후각의 시각화 |

**논리·고난도**
- 지문 구절 두 개 이상을 정확히 인용한 뒤 근거 없는 의도를 얹기(인용은 맞지만 말이 향하는 방향이 다르다).
- **'A는 B와 달리'**: A에 있고 B에 없는지 **둘 다** 확인해야 풀리게 한다. B에도 있는 요소(보조 용언, 음성 상징어, 반복 표현)를 쓰면 함정이 된다.
- **보편화 함정**: 한 작품에만 맞는 판단을 '모두'로.
- **〈보기〉 논점을 엉뚱한 인물·대목에** 붙이기, **텍스트 근거 없는 장면에** 붙이기.
- **비유를 실제 변화로**: '달빛 대낮' → 시간이 낮으로 바뀐 것으로.
- **발화 주체 바꾸기**: 한 인물의 의구심을 다른 인물에게.
- **동기와 행위 구분**: 행위는 죄이나 동기는 정성인 경우를 섞기.
- **지칭 대상 추적**: 변장한 인물을 인물마다 누구로 인식하는가.
- **조건 구분**: 장면마다 대상이 무엇의 조건인가.
- **두 상황의 심리를 한 상황에 뒤섞기**.
- **[A]~[E] 구간 사이의 기대 ↔ 실상 연결**.
- **과도한 확장**: 막연한 기약 → '함께 터전을 마련할 용기'.
- **비유는 맞고 효과만 덧붙여 틀리게**: '유대감 심화'.
- **태도 성격 바꾸기**: 정중한 말투 → 행적 존중, 궁금증 → 확인 결과, 겸손한 자기 성찰 → 욕망 추구.
- **원관념과 보조관념 혼동**, **시적 공간 위치 바꾸기**('내 속' → '세상').
- **결핍-단절 트랩**, **참인 앞 절로 거짓인 뒤 절 덮기**.

**학교 시험에서 자주 나오는 것**
- 없는 결과 삽입: '해소', '극복', '승화', '평정', '안식처', '성찰', '결심'.
- 정서·가치 뒤집기: 적극적 소망 → 절망, 의문·기대 → 확신.
- 한 단어 사실 차이: 다음 해 → 혼인한 해, 미래 → 현재 시제, 초승달, 실수로, 의식적 ↔ 무의식.
- 갈래 지식 오류: 재담의 독립성, 후렴구의 음악적 기능을 주제 강조로, 향가 구수.
- 수사법 정의와 실제 표현의 불일치.
- 극적 효과 반대로: 극중 상황을 직접 설명해 몰입을 방해하는데 '몰입을 돕는다'.
- 서술 시각 오판: 주관적 시선을 객관적 묘사로.
- 소재·시어 쌍 맞바꾸기, 원작-패러디 같은 자리 시어 뒤바꾸기.
- 다른 인물의 말을 '나'의 말처럼, 대화·사건 순서 왜곡.

## 외부 작품 〈보기〉 비교 1문항
<!-- 단계: 설계, 작성 -->
앞 세트에 1문항을 덧붙이는 형식이다.

- 발문: **"윗글과 〈보기〉를 비교하여 감상한 내용으로 적절하지 않은 것은? [3점]"**
- 〈보기〉에는 외부 작품 전문만 넣는다. 문항 번호는 앞 세트에 이어 붙이고, 응답에 어느 지문 뒤에 붙는지 적는다.
- 설계 순서
  1. 두 작품의 **공통 축**을 찾고 그 축 위에서 **어디서 갈리는지** 정한다(예: 둘 다 타인의 울음을 목격한다 → 울음의 내력을 아는가에서 갈린다).
  2. 표현상 특징 선지를 섞는다: 시간 구성(역순행 ↔ 순행), 시제(현재형 종결의 현장감 ↔ 과거형 진술), 비유 방식(직유 ↔ 변신의 비유), 어조와 문장 부호(과거형 반복의 담담함 ↔ 느낌표 한 번), 추측·의문형 ↔ 부정형 진술.
  3. 내용 선지: 접촉 여부, 목격의 계기(우연히 ↔ 찾아감), 시선의 방향, 주고받는 방향, 대상의 수(혼자 ↔ 떼).
  4. 연결 어구를 섞는다(①③ '~것과 달리', ②⑤ '~데 비해', ④ '모두').
  5. 길이 80~95자, 정답은 길이 순위 2~3위.
- 해설: 공통 해설 형식(출제 포인트 / 정답 해설에 정답인 까닭과 함정 설계 / 오답 분석 4개)에 '수업에서 짚을 점'을 정답 해설 끝에 덧붙인다.

## 갈래별 출제 포인트
<!-- 단계: 설계, 작성 -->
**현대시**
- 단골: 표현상 특징(공통점·차이점), ㉠~㉤ 시구의 의미·기능, [A][B] 연 비교, 화자의 태도·정서 변화, 〈보기〉(작가론·시대 배경·비평 개념·외부 시) 감상, 이미지의 기능.
- 개념어: 공감각(전이 방향 정확히), 감정 이입, 객관적 상관물, 역설·반어, 도치, 설의, 수미상관, 대구, 영탄, 음성 상징어, 상승/하강 이미지, 원경→근경, 시선 이동, 행갈이, 통사 구조 반복, 경어체, 색채 대비, 관조적 거리, 물아일체.
- 오답 경향: 공감각 방향 뒤집기, 하강 이미지를 상승으로, 시어의 주체 바꾸기, '모두/달리' 범위.

**고전시가(시조·가사·고려가요·향가·한시)**
- 단골: 화자의 처지와 태도, 공간·시간 이동, 대상(임·자연)의 의미, 〈보기〉(갈래 해설·작가 생애·충신연주지사·강호가도), 연시조의 내적 통일성, 후렴구 기능.
- 개념어: 3음보·4음보, 분연체, 후렴구, 월령체, 충신연주지사, 안분지족, 강호가도, 연군지정, 의인화, 대구, 설의, 영탄, 향찰 음차·훈차, 10구체 낙구.
- 오답 경향: 후렴구의 음악적 기능을 주제 강조로, 연시조 수(首)별 특징 섞기, 고어 풀이 오류.
- 지문: 원문 그대로(옛한글 포함), 필요하면 현대어 풀이·어휘 풀이(*) 병기. 한시·향가는 원문과 해독을 함께.

**고전소설**
- 단골: 서술상 특징, 인물의 행동·발화 의도, ㉠~㉢ 서사적 기능, [A][B] 대비, 소재 기능, 삽입 시의 기능, 〈보기〉(갈래론·환몽 구조) 감상, 사건 순서.
- 개념어: 전기성, 우연성, 편집자적 논평, 요약적 서술, 장면 제시, 삽입 시, 서술자 개입, 액자 구조.
- 오답 경향: 발화·행위 주체 바꾸기, 동기와 행위 혼동, 지칭 대상 오인, 〈보기〉 논점을 엉뚱한 인물에.

**현대소설**
- 단골: 서술 시점·서술자의 태도, 인물의 인식·심리, 장면 전환, [A][B] 서술 방식, 대화의 기능, 〈보기〉(세태소설·리얼리즘·아이러니·신뢰할 수 없는 화자) 감상.
- 개념어: 1인칭 관찰자·주인공, 전지적, 초점화, 의식의 흐름, 요약과 장면, 공간적 배경의 상징성, 아이러니, 풍자.
- 오답 경향: 다른 인물의 인식을 '나'의 것으로, 장면 지어내기, 범위 넓히기, 시간 순서 왜곡.

**수필·교술(고전 수필·설·기·편지)**
- 단골: 글쓴이의 깨달음·태도, 유추 구조(경험 → 깨달음), 서술 방식(문답, 인용, 대비, 예시), 외부 수필과 비교.
- 오답 경향: 유추의 원관념·보조관념 혼동, 경험 순서 바꾸기, 깨달음의 대상 바꾸기.

**극(희곡·시나리오·탈춤)**
- 단골: 지시문 기능, 인물의 갈등과 태도, 무대 장치·소품, 연출 계획·영상화 제작 노트(S#), 극적 효과(몰입 vs 거리), 재담 구조.
- 개념어: 지시문, 방백, 독백, 소격 효과, 관객 참여, 재담, 장면 번호, 몽타주, 오버랩, 클로즈업.
- 오답 경향: 극적 효과 방향 뒤집기, 연출 '의도'에만 오류, 발화 주체 추적 오류.

**수사법 표기**: 대부분 명칭으로 쓴다. 정의로 풀어 쓰는 학교도 있다(반어 = '참뜻과 반대되는 말을 하여…', 역설 = '표면적으로 모순되나 내면의 진실을 드러내는…').

## 교재 기반 출제
<!-- 단계: 설계 -->
- 교재에 실린 문항을 전부 목록으로 만들고(서술자 개입 찾기, 대구 찾기, 공통 표현법, 사건·공간 순서, 외부 작품 비교 등) **그 각도는 피한다.** 교재에 없는 각도를 중심으로 하되, 내신 대비 기본형도 두텁게 섞는다.
- 지문이 길면 두 지문으로 나눈다.
- 작품 정리·지문 분석 자료와 함께 문항을 낼 때는 분석에서 짚은 포인트를 문항으로 쓰고, 오답은 그 분석 설명을 비틀어 만든다(학생이 자료를 제대로 읽었는지 확인).
- 내신 문학 난도는 **교재에 실린 관련 외부 작품을 본 작품과 엮어서** 올린다.
- 고난도 내신: 작품 수를 늘리고, 외부 작품 〈보기〉를 겹치고, 선지에 두 작품의 인용과 해석을 한 문장으로 담고, 갈래·개념 지식을 결합한다.
