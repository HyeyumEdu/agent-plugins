# 독서(비문학) 출제 지침

공통 지침과 함께 적용한다. 2028 체제의 '독서와 작문' 통합은 `guide.py 화법작문`에 있다.

## 세트 구성
<!-- 단계: 설계 -->
- 기본: **지문 1개 + 7문항**(어휘 바꿔 쓰기 문항 제외). 인문·철학 주제는 5문항 세트도 쓴다.
- 세트 안 순서: **내용 일치·불일치 → 핵심 구절(㉠·네모 개념) 추론 → 〈보기〉 적용**.

| 번호 | 유형 | 특징 |
|---|---|---|
| 1 | 전개 방식 / 비판 이유 추론 | 지문 전체 구조 |
| 2 | 내용 이해(적절하지 않은 것) | 세부 정확성 |
| 3 | 문맥 추론 / 전제 파악 / 핵심 구절 의미 | 논리 추론 |
| 4 | 〈보기〉 적용 | 원리를 새 상황에 |
| 5 | (가)·(나)·〈보기〉 통합 비교 [3점] | 복수 텍스트 종합 |
| 6~7 | 대상 대조, 사례 판단, 2차 〈보기〉 | 확장 세트용 |

- 주제 통합 (가)(나)는 학자별·관점별 대조 문항을 둔다.
- 읽기 지문 뒤에 작문 문항(논증 초고 평가, 고쳐쓰기)을 붙이는 융합 구성도 쓴다.
- **차별 유형을 한 세트에 1~2개 넣는다.**
  - **비판 이유 추론**: "㉮가 비판받는 이유를 추론한 내용으로 적절하지 않은 것은?" — 지문에 실제로 근거가 있는 비판만 맞는 선지로 둔다.
  - **전제 찾기**: "ⓐ의 전제로 가장 적절한 것은?"
  - **두 개념 대조**: "㉠과 ㉡을 이해한 내용으로 가장 적절한 것은?" — 선지는 'A는 ~하는 반면, B는 ~한다'.
  - **3방향 비교**: (가)·(나)와 〈보기〉의 새 학자(갑·을·병)를 교차 비교한다. 주제 통합의 최고 난도.
  - **의미 추론**: "ⓐ의 의미를 추론한 내용" — 어휘 바꿔 쓰기보다 한 단계 높은 문맥 의미.

## 〈보기〉 설계
<!-- 단계: 작성 -->
- **3원칙**
  1. **실험 비교형**: 수치 조건 하나만 다르게(검사 A/B/C, 구간 길이 수치표).
  2. **외부 사례 + 지문 교차 비교**: 실제 역사·과학 사례, 이름 붙은 학자들의 비교표.
  3. **법적 사례 + 적용 범위 판단**: 판례형 사례(C사·을 / D사·병).
- 〈보기〉는 5~8문장으로 쓰고 세부 조건을 명시한다. 추상적 자리표시 대신 실제 사례·실명 학자를 쓴다.
- **[3점]은 두 조건 이상을 함께 판단**해야 풀리게 한다(예: 요건 A 충족 + 예외 B 해당 여부).
- 더 쓸 수 있는 〈보기〉: 조건표를 보고 방식 고르기, 다른 관점의 글로 비판하기("필자가 위 글을 비판한다면"), 분류표 적용, 논증 사례를 오류 유형에 대응, 인물형 해석 틀, 다른 장르에 이론 적용, 새 수치로 지수 계산, 가설을 입증할 실험 고르기(ㄱ~ㄷ), 판례형 사례 판단.
- **상호 비판형(㉮ ↔ ㉯)**: 오답은 지문에 없는 비판 근거를 끼워 넣거나 학자의 입장을 서로 바꿔 만든다. 정답은 지문에 실제로 명시된 차이점에서만 도출한다.

## 오답 함정
<!-- 단계: 작성 -->
**기본 7종**: 방향 역전, 대상 교체, 과도한 단정, 미언급 내용 삽입, 인과관계 조작, 범위 왜곡, 서술 구조 왜곡.

**내용 일치**
- 'A하거나 B한다'를 'B가 아닌 A'로 바꿔 **한쪽을 지운다.** (내용 일치 문항에 이것이나 정도 단정을 최소 하나 넣는다.)
- 지문의 진술을 부정형으로 뒤집는다. '부정하지 않는다 / 전제하지 않는다'를 긍정으로 바꾼다.
- 정도 단정: 원문 '이상'을 '절반에 해당'으로.
- 정반대 진술: 인정받지 못함 → 쉽게 얻음.

**사례 적용**
- 행동마다 전략 이름에 정확히 짝짓게 하고, 겉모양이 비슷한 것(사진이 들어 있음 → '시각 자료 = 도해 조직자')으로 잇는 함정을 둔다.
- 이론과 그 비판론을 사례에 적용할 때 1단계·2단계·다단계를 구분하게 한다.
- 하나의 관점을 공식처럼 세워 다섯 선지를 판정하게 한다.

**추론·비교**
- 인과 방향 뒤집기(결과를 원인으로), 원인과 결과를 반대로.
- **학자별 키워드 섞기**, 연구 계보 섞기.
- 〈보기〉 **정의어 한 단어 바꿔치기**('대표적 구성원' → '전체').
- 부품·요소 기능 혼동(변동을 억제하는 회로 vs 변동을 만드는 스위치), 처리 순서 뒤집기, 크기·주파수 비교 방향.
- **원리를 극단 조건까지 기계적으로 늘리기**(스위치가 계속 켜진 경우).
- '특별한 경우'를 대안 방식의 단점이 치명적인 경우로 추론하게 하기.
- **시대착오**: 오늘날의 역할을 과거의 원인으로.
- 주체·범주 바꿔치기(시간 분할 ↔ 데이터 분할, 내용 ↔ 형식, 개별 정당 분석 ↔ 정당 체계 분석), 정의의 주체 ↔ 객체 뒤집기.
- 시점·순서 뒤집기('충돌 후에야 형성').
- 이론의 설명 범위 넘기.
- 대비를 다른 대비로 왜곡(낮/밤 대비를 유리/불리 상황으로).
- 한정 표현 하나: '법률에 규정된', '사후에만', '관련 없이'.
- 비교 방향 뒤집기, 자료 일부만 활용하거나 자료를 잘못 읽은 의견.

## 분야별 오답·〈보기〉
<!-- 단계: 작성 -->
| 분야 | 주로 쓰는 오답 | 〈보기〉 설계 |
|---|---|---|
| 법 | 요건 미끄러뜨리기, 적용 영역 혼동(국가의 기본권 제한 요건을 사인 간 계약에), 조건 충족 여부 반대, 일반 보증인 권리를 연대 보증인에게, 규정 적용 범위, 한정 표현 | 판례형 사례 2개(약정 무효 사례 + 무관한 제한 계약), 같은 사실에 요건 하나만 바꾼 사례 쌍 |
| 경제 | 인과 방향 뒤집기, 곡선 이동 방향·원인 혼동, 단기/장기 효과 혼동, 정책 주체 바꾸기, 정보 비대칭 당사자 바꾸기 | 수치 조건 하나만 다른 두 상황, 정책 시점 차이 |
| 과학 | 원리를 극단 조건까지 확장, 인과 역전, 수치 비교 방향, 이론 설명 범위 넘기, 조건(온도·농도) 바꾸기 | 실험 비교형, 수치표·파형 그림, 경계 조건 사례 |
| 기술 | 부품 기능 혼동, 처리 순서 뒤집기, 방식 간 장단점 교차, 크기·주파수 비교 방향 | 방식 선택 조건표, 행렬·표에서 역추론 |
| 인문·철학 | 학자별 키워드 섞기, '부정하지 않는다'를 긍정으로, 비판 이유를 지문에 없는 근거로, 관점 하나를 기계 적용, 전제 오인 | 새 학자 갑·을·병의 견해로 3방향 비교, '필자가 위 글을 비판한다면', 사례 판단 |
| 사회 | 1단계·2단계·다단계 구분, 시대착오, 연구 계보 섞기, 개별 분석 ↔ 체계 분석 | 이론과 비판론을 사례에 적용, 단계 구분 사례 |
| 예술 | 개념의 시대·주체 바꾸기, 이론을 다른 장르에 적용할 때 범위 넘기 | 다른 장르 작품에 이론 적용 |

그림이 필요한 지문(파형·그래프)은 글로 설명하고 그림 자리를 표시한다(시험지 파일에는 그림을 넣을 수 없다).

## 어휘 문항
<!-- 단계: 작성 -->
- **2단 대체**: 구별되다 = 다르다, 부여하다 = 주다처럼 한 번 더 바꿔야 맞는지 판단되게 한다.
- **다의어 구별**: '틀(규범·가정)에서 어긋나다' vs '공간·상태에서 빠져나오다'.
- 문맥상 의미, 사전적 의미(작동, 초래, 규명 등)를 묻는다. 오답은 대상과 맞지 않는 한자어로 만든다.

## 선지 길이
<!-- 단계: 작성, 검수 -->
- 수능 독서 기출 중앙값은 〈보기〉형 53자, 그 외 33자다. 문학보다 짧다.

## 내신 독서
<!-- 단계: 설계 -->
- 교과서 지문과 수능 연계 교재 지문을 섞어 지문당 3~6문항.
- **지문마다 서술 방식 문항**을 하나씩 두는 학교가 있다.
- 어휘 문항(문맥상 의미, 사전적 의미), **외부 문학 〈보기〉**를 독서 지문에 붙이기(지문 속 인물에게 할 말, 화자와 글쓴이의 가상 대화), **수치·도표 〈보기〉 적용**(고배점)을 대비한다. 지문은 맞혀도 이 유형들에서 빗나가기 쉽다.
- 어려운 지문(법적 의제, 인과 이론 등)은 수업 자료를 만들 때 **개념 구조도를 먼저** 그리고, 학생이 빠지기 쉬운 오개념을 겨냥해 설명한다.
