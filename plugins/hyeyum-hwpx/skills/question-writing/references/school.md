# 학교 맞춤 내신 출제 지침

학교 중간·기말고사 대비 모의고사, 단원 평가 묶음, 교재 지문 변형 문제를 만들 때 적용한다. **이 지침의 학교 형식이 수능형 규칙보다 우선한다.** 학교 시험은 학교마다, 해마다 형식이 달라서 수능형 기준을 그대로 쓰면 유형에서 빗나간다.

## 학교 프로파일
<!-- 단계: 설계 -->
- 학교별 형식은 사용자가 가진 **학교 프로파일 파일**(예: `학교프로파일/○○고2_문학.md`)에서 읽는다. 파일이 있으면 맨 먼저 읽고, 없으면 지난 시험지를 받아 분석해(`guide.py 분석`) 만든 뒤 쓴다. 둘 다 없으면 이 문서의 '학교 시험에 자주 나오는 형식'과 수능형 기준을 섞어 쓰고, 첫 시험이 끝나면 프로파일을 만들자고 알린다.
- 같은 학교도 해마다 바뀐다(긍정 발문 비율이 한 해 만에 크게 바뀐 예가 있다). **가장 최근 시험**을 기준으로 한다.
- 프로파일 양식(분석 뒤 이 꼴로 저장한다)

```markdown
# ○○고 ○학년 ○○ 프로파일 (마지막 갱신: 20○○ ○학기 ○차)
- 교과서: 출판사·대표 저자
- 형식: 선택형 __문항 __점(배점 __~__, 0.1 단위), 서·논술형 __문항 __점(소문항 배점)
- 영역 비중: 문학 __ / 독서 __ / 화법 __ / 작문 __ / 문법(음운·단어·문장·의미·중세·맞춤법) __
- 발문: 긍정 __% / 부정 __%
- 조합형 수: 있는 대로 __, 개수형 __, 짝짓기 __, O/X 표 __
- 외부 작품 위치: 지문 / 〈보기〉 / 선지 안, 이중 〈보기〉 문항 수
- 대표 문형 3~4개:
- 오답 빈도 상위 5(코드):
- 고배점 문항 유형:          저배점 문항 유형:
- 선지 길이·문체: (길이 범위, 수사법 명칭/정의 풀이, 개념어 밀도, '~라는 점에서' 사용 여부)
- 서·논술형: 〈조건〉 상자 문구, 문장 틀, 부분 점수·감점 규정
- 최근 빗나간 유형(다음에 반드시 넣을 것):
- 과잉 대비(비중을 줄일 것):
```

| 프로파일 항목 | 출제에 반영하는 법 |
|---|---|
| 문항 수·배점 | 그대로(0.1점 단위 차등, 합계 100 또는 선택형+서술형 합 100) |
| 긍정/부정 발문 비율 | 최신 시험 비율 |
| 조합형 수 | 있는 대로·개수형·짝짓기·O/X 표 문항 수 |
| 외부 작품 위치 | 학교가 넣는 자리(지문 / 〈보기〉 / 선지 안)에 넣는다 |
| 대표 문형 | 선지 틀로 쓴다 |
| 오답 빈도 상위 5 | 오답 설계에 먼저 배치 |
| 서·논술형 | 〈조건〉 상자·문장 틀·소문항 배점·감점 규정을 그대로 흉내 |
| 최근 빗나간 유형 | 반드시 포함 |

## 시험 정보와 범위 자료
<!-- 단계: 설계 -->
- 먼저 모은다: 학교·학년·과목, 교과서(출판사·저자), 시험(학년도·학기·차·날짜), 범위(단원·쪽·작품명 / 수능 연계 교재 지문 / 학교 프린트 / 추가 자료), 지난 시험 형식, 요청 분량(회차 × 문항 수), 결과물 형식. 모르면 묻는다.
- 범위가 애매하면(대단원 평가 중 일부만 범위) 범위에 해당하는 지문·문항만 쓴다.
- 자료
  1. **교과서 본문**: 사용자가 준 것만 쓴다. 사진·PDF는 정확히 옮기고 판독이 불확실한 곳을 표시한다.
  2. **학습 활동·지도서 예시 답안**: 학교가 활동 문항을 변형해 내는 일이 많다.
  3. **수능 연계 교재 지문**: 범위에 들어가면 교과서와 같은 비중으로.
  4. **외부 작품**: 교재에 실린 관련 작품(같은 작가·주제·갈래)을 **작품 수보다 넉넉히** 모은다. 학교는 외부 작품을 〈보기〉나 선지 안에 넣어 난도를 올린다.
  5. **추가 자료**: 교사가 준 관련 글은 교과서 지문과 엮어 주제 통합 세트로 쓴다.

## 회차 설계
<!-- 단계: 설계 -->
| 요청 | 설계 |
|---|---|
| 학교 형식 모의고사 n회 | 회마다 학교 형식(문항 수·배점·영역 비중) 그대로. 지문은 회차마다 다르게 배분하되 핵심 작품은 회차마다 다른 축으로 반복 |
| 지문별 변형 n문항 × m회 | 같은 지문이라도 회차마다 축·구간·기호·〈보기〉를 바꾼다 |
| 범위 전체 60문항 단위 | 지문당 문항 수를 범위 비중에 맞춰 배분, 세트 번호를 이어서 |
| 작품 1편 30제 | 표현·내용·기호·[A][B]·〈보기〉 3~4종·외부 작품 비교·서술 방식을 고르게, 난도 3단계(기본 10·중 12·고 8 등) |
| 단원 평가 묶음(여러 파일 합치기) | 범위 문항만 골라 번호를 다시 매기고 정답·해설을 문항 순서와 맞춘다 |

- 한 회차 안에서 같은 작품을 두 세트로 쓰지 않는다.
- 회차마다 교과서 지문과 추가·외부 자료를 섞는다.
- 회차마다 정답 번호별 개수가 고르게 되게 한다.
- 학교가 지문 없이 〈보기〉만으로 푸는 단독 문항을 내면 1문항 넣는다. 지문마다 서술 방식 문항을 내는 학교면 그 비율을 따른다.
- 세트 설계표에 배점, 문항 유형 코드(`guide.py 오답코드`의 T·V·M·R·L·W 코드), 오답 코드, 학교 문형 칸을 더한다. 세트 배점 합과 최고 배점 문항 유형도 적는다.

## 학교 시험에 자주 나오는 형식
<!-- 단계: 설계, 작성 -->
- **배점**: 소수 첫째 자리까지 차등. 고배점은 조합형·이중 〈보기〉·외부 작품 비교·문법 개념 적용, 저배점은 표현·내용 일치.
- 단서 조항('단, ~으로 함')을 표기한다.
- **한 시험지에 발문 유형을 8가지 이상** 섞고, 조합형은 6~9문항(적은 학교는 3문항 안팎).
- 긍정 발문은 공통국어·화법과 언어 약 50%, 문학 약 33%가 흔하지만 학교마다 25~70%로 넓게 다르다. 프로파일을 따른다.
- 자주 나오는 발문 유형: 있는 대로 고르기(ㄱ~ㅅ), 있는 대로 + 개수형, 이중 〈보기〉, 표 분류(예/아니요), 개수형(정답 개수 1~2개가 많다), 짝 선지, 조건 다중 충족, 빈칸 채우기, 학습지 O/X 판단('판단 결과가 적절하지 않은 것', '모두 바르게 표시한 학생'), 근거 확인형, 매체 재구성(연출 계획), 외부 시구 선지형, 수정형, 예문 생성형, 학생 대답 ⓐ~ⓔ 고르기, 게시판 Q&A, 구조화 표, 도식, 집필 구상 역추적, 〈보기〉 유형별 범주 배정.
- **외부 작품**: 지문이 아니라 〈보기〉로만 넣는 학교가 많고, 고어 원문도 그대로 싣는다. 선지 안에 외부 작품 3~5편을 넣는 학교도 있다. 지문 없이 〈보기〉만으로 푸는 단독 문항이 나오기도 한다.
- **이중 〈보기〉**: 〈보기 1〉 이론·해설·작가 생애 + 〈보기 2〉 외부 작품. 한 시험에 1~5문항, 고배점.
- **이론 글 〈보기〉**: 문학 관점론(표현론·반영론·효용론·내재론) 이름 짝짓기, 수용론 도식, 심리학 개념, 꿈 이론, 인간형 분류, 사회학 자본 개념, 낯선 평론 개념 적용.
- **짝짓기·분류**: 시어 관계를 〈보기〉 ⓐ~ⓔ에 대응, [A] 사회 / [B] '나'의 시선에 ㉠~㉥ 나누기(다른 인물의 말을 '나'의 말처럼 보이게 하는 함정), 교사 질문 1~5 ↔ 답변 ㉮~㉲.
- **영상화·연출 대화**: 학생 A~C가 각각 2~3번 발언하고 '있는 대로' 고른다. 한 학생의 발언 안에 맞는 말과 틀린 말을 섞는다. 시나리오 제작 노트('S#○○에서 (기법)함으로써 (의도)해야겠다' — 오류는 의도 한 구절에), 연출 계획('~역할을 맡은 배우에게 ~한 표정으로 연기해 달라고 해야겠다').
- **표 자료형**: 작품/맥락/감상 칸의 이름과 내용 바꿔 끼우기, 비교 노트 표(공통점·차이점) 개수형, 진위 판단 표.
- **복합 세트**: 시대·갈래를 섞는다(시조 + 고전 수필, 탈춤 + 현대 희곡, 현대시 + 가사 + 시조, 고려가요 + 현대시, 현대 소설 + 현대시). 세트당 3~5편 + 외부 〈보기〉.
- **3작품 교차**: '(가)와 (다)는 모두', '(나)는 (가)와 달리', '~점에서 (나)와 유사하고 (다)와 다르다'.
- **화자를 여러 관점으로 볼 때**: '실연한 여인 / 유랑민 / 지식인으로 볼 경우'.
- 범위 밖 인문 지문(관점 비판 + 사례 적용)이 나오기도 한다.

## 학교 선지 문체
<!-- 단계: 작성 -->
- 학교 문형이 수능형과 다르면 **학교 문형을 따른다.**
  - 비교 틀: '~라는 점에서 〈보기 1〉의 '~'와 같다/다르다', '㉡은 ㉠과 달리', '(가)와 (나)는 모두', '(가)는 ~한다면, (나)는 ~'.
  - 긴 선지(50~150자): "(가)에서 'A'인 것에서 ~을, (나)에서 'B'인 것에서 ~을 확인할 수 있다"처럼 두 작품을 각각 인용하고 해석한다. 인용 구절 + 기능 + 효과 세 요소를 결합한다.
  - 기호 문항은 '㉢: ~' 콜론형 한 줄, 〈보기〉 감상은 '~하는군 / ~있어'.
  - '[A]를 지지하는 입장에서 ⓐ를 근거로 [B]를 비판'.
  - 문법 선지는 짧은 사실 판단형이 많다.
- **수사법**: 대부분 명칭으로 쓴다. 학교가 정의로 풀어 쓰면 따라 쓴다('참뜻과 반대되는 말을 하여…' = 반어, '표면적으로 모순되나 내면의 진실' = 역설, '대비되는 두 사실이 모두 마땅치 않을 때 쓰는 부사' = 차라리).
- 개념어 밀도가 높은 학교가 있다: 양가감정, 순환적 구조, 객관적 상관물, 의식의 흐름, 장소성, 재담 구조, 관념의 형상화.
- 선지 길이 기준은 학교 시험지에서 잰 값을 쓴다(`check_items.py --school`은 수능형 길이 기준을 참고로만 낸다).

## 학교 시험의 오답과 난도
<!-- 단계: 작성 -->
- 오답은 대부분 **지문 대조로 확인되는 한 단어 차이**다: 범위('모두/달리'), 방향, 주체, 사실.
- 문학 오답 빈도(높은 순): 주체 교체·'달리/모두' 범위 > 앞 절 참·뒤 절 거짓 > 없는 결과 삽입 > 인과·목적 왜곡 > 정서·가치 뒤집기 > 〈보기〉 개념 오적용 > 한 단어 사실 차이 > 갈래 지식 오류.
- 그 밖에: 기법은 맞고 효과는 틀림, 시어 쌍 맞바꾸기, 작품 정보 교체, 특징과 근거 예시 불일치, 인용 구절과 장면·인물 매칭 오류, 이론 하위 개념 바꿔치기, 두 작품을 묶은 진술에서 한쪽만 틀리게, 기능 서술 '~하며 ~하고 있다'의 두 요소 중 하나만 틀리게.
- **학생이 실제로 틀리는 문항**: 개념어가 화려한 오답을 고른 경우가 가장 많다. 정답은 지문 근거에 대응하는 무난한 문장이었다. 문법은 짝 선지 한쪽만 틀린 문항.
- 난도를 올리는 요인: 시어 10여 개를 묶은 유사·대립 판단, 세부 문구 내용 일치, 긴 시나리오·대화의 발화 주체 추적, 세트당 작품 3~5편 + 외부 〈보기〉, 한문·향찰 원문 + 해독, 갈래 지식, 낯선 이론 개념, 문법 다단계 판단.
- 오답이 분명한 학교(난도 중하)를 고난도로 대비할 때는 같은 유형을 쓰되 오답을 한 지점만 미세하게 틀리게 한다.

## 자주 빗나가는 유형
<!-- 단계: 설계 -->
작품·조항은 대부분 맞혀도 다음 유형에서 빗나가는 일이 반복된다. 모의고사에는 유형을 골고루 넣고, 프로파일의 '최근 빗나간 유형'은 반드시 넣는다.

- 외부 작품 〈보기〉(작품 수보다 넉넉히 준비), 이중 〈보기〉
- 이론 글 〈보기〉
- 짝짓기·분류
- 영상화·연출 대화
- 어휘 문항(문맥상 의미·사전적 의미)
- 지문마다 반복되는 서술 방식 문항
- 수치·도표 〈보기〉
- 범위 밖 인문 지문
- 문법 서·논술형
- 화법·독서처럼 범위가 작아 소홀해지는 영역

## 학교 맞춤 검수

- 문항 수·배점 합·발문 비율·조합형 수·외부 작품 위치가 설계표(프로파일)와 같은가.
- 모든 지문·문항이 시험 범위 안인가(범위 밖 작품은 〈보기〉로만).
- 정답표와 해설의 번호가 문항 순서와 일치하는가, 회차의 정답 분포가 고른가.
- 선지 길이·정답 길이 순위는 학교 기준으로 본다.
- 응답에 회차·문항 수·배점 합, 정답 분포, 지문 구성, 원본과 달라진 점, 확인이 필요한 부분, 임의로 정한 배점을 적는다.
