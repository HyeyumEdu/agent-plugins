# 서술형·논술형 출제 지침

서술형은 답이 하나의 방향으로 모여야 채점이 흔들리지 않는다. 그래서 학생이 **무엇을, 몇 가지, 어떤 형식으로** 쓸지 발문과 〈조건〉으로 좁힌다.

## 기본 원칙
<!-- 단계: 전체 -->
- **"쓰시오"로 끝내지 않는다.** 무엇을, 무엇을 근거로, 어떤 형식으로 쓰는지 적는다.
- 소문항별 배점을 적는다(예: (1) 2점, (2) 3점). 소문항 배점의 합은 문항 배점과 같아야 한다.
- 정답지에는 **예시 답안 + 채점 기준표 + 감점 규정**을 쓴다. 예시 답안은 완결된 문장으로, 〈조건〉을 스스로 모두 지키게 쓴다.
- 근거는 지문 안에 있어야 한다. 열린 해석이 되면 채점 기준이 흔들린다.

## 문항 구성
<!-- 단계: 설계, 작성 -->
1. **발문**: 무엇을, 무엇을 근거로, 어떤 형식으로.
2. **〈조건〉 상자**: 포함할 요소, 형식, 분량, 금지 사항.
3. **답안 문장 틀**(작성 형식): 예) '㉮는 ~을/를, ㉯는 ~을/를 의미한다. 왜냐하면 ~ 때문이다.'
4. **소문항 번호와 배점**: (n-1)(n-2)…
5. **해설**: 예시 답안 + 채점 기준표 + 감점 규정.

문장 틀 예
- "[A]는 담의 ~에 위치한 ~를 의미한다." — 위치 1점, 의미 2점
- "첫째 ~, 둘째 ~군."
- "㉠은 ~이기 때문에 ~이다."
- "( )을/를 초월하여 ( )을/를 확신" 같은 빈칸 양식

분량·형태 지정
- 음절 수 지정('수미'·'상관'처럼 2음절, 4음절), 3어절로 찾아 쓰기, 한 단어로 쓰고 각각의 의미 서술.
- "효과 2가지를 완결된 문장으로" — 세 번째 답안부터는 채점하지 않음.

## 유형별 틀
<!-- 단계: 작성 -->
| 유형 | 발문 틀 | 배점 예 |
|---|---|---|
| 시어 의미 서술 | (나)에서 대상에 대한 화자의 인식 변화를 근거로 ㉮, ㉯의 의미를 〈조건〉에 맞게 서술하시오. | 의미 각 1 + 근거 2 = 4 |
| 소재 찾기 + 서술 | ①에 해당하는 시어를 찾아 쓰고(2점), 그 의미를 〈조건〉에 맞게 서술하시오(4점). | 2+4 |
| 공통 표현 방법 | 두 표현에 공통으로 쓰인 표현 방법을 쓰고, 각각의 효과를 서술하시오. | 1+2+2 |
| 외부 작품 연결 | 〈보기〉의 작품과 (가)의 공통 특징을 쓰고, 그 기능을 서술하시오. | 2+3 |
| 시대 배경 + 대조 | 〈자료〉를 참고하여 ㉠이 의미하는 바를 쓰고, 〈보기〉의 작품과 대조하여 그 차이를 쓰시오. | 2+2+2 |
| 빈칸 채우기 | 〈보기〉의 ( ㉠ )에 들어갈 말을 2음절로 쓰시오. | 음절 수 지정 |
| 소설 시점 | 시점을 쓰고, 그 시점을 쓴 궁극적 목적과 〈보기〉 개념의 결과를 비유적으로 나타낸 부분을 3어절로 찾아 쓰시오. | 1+2+2 |
| 문법 적용 | 예)의 형식대로 [A]에 들어갈 말을 서술하시오. | 발음·현상 1 + 유형 1 |
| 탐구 절차 | 순서도의 단계 번호와 최종 표기를 쓰시오. | 단계 + 표기 |
| 발음 과정 | [ ] → [ ] → [ ]로 발음 과정을 쓰고 적용된 변동을 쓰시오. | 과정 + 명칭 |
| 직접 구성 요소 + 의미 관계 | (1) 직접 구성 요소를 분석하고 (2) 의미 관계를 '㉠은 ~이기 때문에 ~이다.' 틀로 쓰시오. | 2+3 |
| 오류 수정 | 밑줄 친 부분을 바르게 고치고 그 이유를 서술하시오. | 수정 2 + 이유 3 |
| 담화 응집성 | (가)~(라) 중 응집성에 어긋나는 문단을 고르고 이유를 서술하시오. | 2+3 |
| 단답 | 시어·배경 명칭을 쓰시오. | 부분 점수 절반 |

## 〈조건〉 문구
<!-- 단계: 작성 -->
- 작품의 내용을 언급하며 구체적으로 서술할 것.
- 완결된 문장('~다.')으로 서술할 것. / 단답형, 단어만 나열한 답안은 점수를 부여하지 않음.
- [작성 형식]을 참고하여 서술할 것. / 예)의 형식대로 답안을 작성할 것.
- ㉮, ㉯의 의미와 근거가 논리적으로 연결될 때 점수를 부여함.
- 근거로 '대상에 대한 화자의 인식(또는 태도) 변화'를 구체적으로 밝힐 것.
- 두 가지를 서술할 것(세 번째 답안부터는 채점하지 않음). / 두 번째 답안부터 채점하지 않음.
- 작품의 구절을 그대로 옮겨 적지 말 것. / 〈보기〉의 내용을 그대로 쓰지 말 것.
- 비유적 표현을 쓰지 말 것.
- 상황과 화자의 감정을 모두 포함할 것.
- 글자 수 제한은 없음.
- 맞춤법·문장 호응 오류 시 문항당 1점 감점.
- 답에 써야 할 용어가 어디서 나오는지(교과서 용어, 〈보기〉의 개념어)와 부분 점수를 함께 밝힌다.

## 채점 기준표
<!-- 단계: 해설 -->
```
문항: [논술형 1] (4점)
예시 답안: ㉮는 ~을, ㉯는 ~을 의미한다. 왜냐하면 ~ 때문이다.

| 요소 | 배점 | 인정 답(핵심어) | 불인정 | 부분 점수 |
| ㉮의 의미 | 1 | 거리감, 배척, 다가가기 어려움 | 시어 반복만 | — |
| ㉯의 의미 | 1 | 포용, 위안, 교감 | — | — |
| 인식 변화 근거 | 2 | 멀리 지나침 → 마음을 이해함 → 곁에 머묾 | 변화 없이 한쪽만 | 한쪽만 1점 |
감점: 작성 형식 미준수 −1, 맞춤법·호응 오류 −1(학교 규정에 따름)
```
- 인정 답은 **핵심어 목록**으로 적어 채점자가 판단을 덜 하게 한다.
- 부분 점수 단위와 감점 규정은 학교 기출을 따른다(학교마다 2점 단위, 2+3, 1~2점 등으로 다르다).

## 품질 점검
<!-- 단계: 검수 -->

- [ ] 근거가 지문 안에 있는가
- [ ] 문장 틀이 답안 길이를 적절히 제한하는가
- [ ] 소문항 배점 합이 문항 배점과 같은가
- [ ] 예시 답안이 〈조건〉을 모두 지키는가
