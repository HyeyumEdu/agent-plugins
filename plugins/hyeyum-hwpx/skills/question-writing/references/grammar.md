# 언어(문법) 출제 지침

공통 지침과 함께 적용한다. 문법 문항은 판정이 하나로 정해져야 하므로, 출제와 해설 모두 아래 **판정 기준**으로만 판정하고 해설에 계산 과정을 적는다.

## 판정 기준: 음운 변동
<!-- 단계: 전체 -->
| 유형 | 현상 | 음운 개수 |
|---|---|---|
| 교체 | 음절의 끝소리 규칙, 비음화, 유음화, 구개음화, 된소리되기 | 0 |
| 탈락 | 자음군 단순화, ㅎ 탈락, ㄹ 탈락, ㅡ 탈락, 동음 탈락 | −1 |
| 첨가 | ㄴ 첨가, 반모음 첨가 | +1 |
| 축약 | 거센소리되기(자음 축약), 모음 축약 | −1 |

- **음운 개수**: 초성 자리의 'ㅇ'은 음운이 아니다(세지 않는다). 받침 'ㅇ[ŋ]'은 센다. 해설에는 변동마다 증감을 적는다.

| 예 | 발음 | 변동 | 개수 |
|---|---|---|---|
| 식혔다 | [시켣따] | ㄱ+ㅎ→ㅋ(축약), ㅆ→ㄷ(교체), ㄷ→ㄸ(교체) | −1 |
| 담가 | [담가] | 담그-+-아, ㅡ 탈락 | −1 |
| 입학 | [이팍] | 거센소리되기(축약) | −1 |
| 열었다 | [여럳따] | ㅆ→ㄷ, ㄷ→ㄸ(교체) | 0 |
| 낱낱이 | [난나치] | ㅌ→ㄷ, ㄷ→ㄴ(비음화), ㅌ→ㅊ(구개음화) | 0 |
| 가족여행 | [가종녀행] | ㄴ 첨가(+1), ㄱ→ㅇ(비음화) | +1 |

- **'ㅎ' 관련 변동**(헷갈려 오류가 잦은 곳)
  - 겹받침 'ㄶ, ㅀ' 뒤에 **자음**으로 시작하는 말 → **자음군 단순화**. 끓는[끌른] = 자음군 단순화 + 유음화(앓는·뚫는·닳는도 같다). 않는[안는], 많네[만ː네] = 자음군 단순화.
  - 뒤에 **모음으로 시작하는 형식 형태소**가 와서 ㅎ이 발음되지 않는 것**만** **ㅎ 탈락**: 끓어[끄러], 싫어도[시러도], 놓아[노아], 쌓인[싸인].
  - 'ㅎ' 뒤 ㄱ·ㄷ·ㅈ, 'ㄱ·ㄷ·ㅂ·ㅈ' 뒤 'ㅎ' → 거센소리되기(축약): 좋고[조코], 입학[이팍], 놓지[노치].
- **연음과 ㄴ 첨가**

| 환경 | 처리 | 예 |
|---|---|---|
| 받침 + 모음으로 시작하는 **형식** 형태소 | 받침을 그대로 옮겨 발음 | 밭에[바테], 옷이[오시] |
| 받침 + 모음으로 시작하는 **실질** 형태소 | 대표음으로 바꾼 뒤 옮겨 발음 | 옷 안[오단], 겉옷[거돋], 헛웃음[허두슴] |
| 합성어·파생어에서 앞말이 자음, 뒷말이 'ㅣ, ㅑ, ㅕ, ㅛ, ㅠ'로 시작 | ㄴ 첨가 | 솜이불[솜니불], 한여름[한녀름], 홑이불[혼니불] |

  - 'ㄷ, ㅌ + 형식 형태소 ㅣ'는 연음과 함께 구개음화가 일어난다(같이[가치], 굳이[구지]). '그대로 옮겨' 발음되는 예로 쓰지 않는다.
- **구개음화**: 받침 'ㄷ, ㅌ'이 **형식 형태소**의 'ㅣ'(또는 '히')와 만날 때. 한 형태소 안(잔디, 느티나무)이나 실질 형태소 앞(밭이랑[반니랑] — ㄴ 첨가+비음화)에서는 일어나지 않는다.
- **비음화와 유음화**
  - 'ㄱ, ㄷ, ㅂ' + 'ㄴ, ㅁ' → 'ㅇ, ㄴ, ㅁ': 국물[궁물], 이튿날[이튼날], 밥물[밤물]
  - 'ㅁ, ㅇ' + 'ㄹ' → 'ㄹ'이 'ㄴ'으로: 침략[침냑], 종로[종노]
  - 'ㄱ, ㅂ' + 'ㄹ' → 'ㄹ'이 'ㄴ'으로 된 뒤 앞 자음도 비음화: 국력[궁녁], 협력[혐녁]
  - 'ㄴ' + 'ㄹ'인데 'ㄹ'이 'ㄴ'으로: 등산로[등산노], 의견란[의견난], 생산량[생산냥]
  - 유음화: 'ㄹ' 앞·뒤의 'ㄴ'이 'ㄹ'로 — 신라[실라], 칼날[칼랄]
- **된소리되기 조건**

| 조건 | 예 | 예외 |
|---|---|---|
| 받침 'ㄱ, ㄷ, ㅂ'(대표음 기준) 뒤의 안울림 예사소리 | 국밥[국빱], 옷고름[옫꼬름] | — |
| 어간 받침 'ㄴ, ㅁ' 뒤 어미의 첫소리 | 신고[신ː꼬], 감다[감ː따] | 피동·사동 접미사 앞: 안기다[안기다] |
| 어간 받침 'ㄼ, ㄾ' 뒤 어미의 첫소리 | 넓게[널께], 핥다[할따] | — |
| 한자어 'ㄹ' 받침 뒤의 'ㄷ, ㅅ, ㅈ' | 발달[발딸], 갈등[갈뜽], 일시[일씨] | 'ㄱ, ㅂ'은 해당 없음(발각[발각]) |
| 관형사형 '-(으)ㄹ' 뒤 | 할 것을[할꺼슬] | — |

  - 경음으로 소리 나더라도 조건 밖이면 '그 조건이 적용된 예'로 고르지 않는다.
- **사이시옷**: 합성어일 것 / 고유어가 하나 이상 포함될 것(한자어+한자어는 곳간·셋방·숫자·찻간·툇간·횟수만) / 앞말이 모음으로 끝날 것 / 뒷말 첫소리가 된소리로 나거나 'ㄴ' 소리가 덧날 것. 예: 냇가, 나뭇잎, 아랫니. 아님: 위층(뒷말이 거센소리), 해님(파생어).

## 판정 기준: 표준 발음법과 음운 체계
<!-- 단계: 전체 -->
| 조항 | 내용 |
|---|---|
| 제9항 | 받침 대표음(음절의 끝소리) |
| 제10항 | 겹받침 'ㄳ, ㄵ, ㄼ, ㄽ, ㄾ, ㅄ' |
| 제11항 | 겹받침 'ㄺ, ㄻ, ㄿ' |
| 제12항 | 받침 'ㅎ' |
| 제13~15항 | 연음 |
| 제17항 | 구개음화 |
| 제18항 | 비음화 |
| 제19항 | 'ㄹ'의 비음화 |
| 제20항 | 유음화 |
| 제23~28항 | 된소리되기 |
| 제29항 | 'ㄴ' 첨가 |
| 제30항 | 사이시옷 발음 |

- 조항 번호를 선지에 쓸 때는 그 조항에 실제로 그 받침·예가 있는지 확인한다(제11항에는 'ㄳ'이 없다).
- **최소대립어**: 나머지가 같고 한 소리만 달라 뜻이 달라지는 쌍 → 두 소리는 모두 음운(발:팔, 게:개). **상보적 분포**: 같은 환경에 나타나지 않는 두 소리 → 기본적으로 한 음운의 변이음. 음성적 유사성이 없으면 둘 다 음운(ㅇ[ŋ]과 ㅎ[h]). 최소대립어를 이루는 두 소리는 상보적일 수 없다.
- **자음 체계**: 마찰음은 치조 'ㅅ, ㅆ'(평음·경음만, 격음 없음)과 후음 'ㅎ'. 비음·유음은 울림소리로 세기로 나뉘지 않는다. 파열음·파찰음은 평음·경음·격음.
- **단모음 10개**: 전설 평순 ㅣ·ㅔ·ㅐ, 전설 원순 ㅟ·ㅚ, 후설 평순 ㅡ·ㅓ·ㅏ, 후설 원순 ㅜ·ㅗ. 고모음 ㅣ·ㅟ·ㅡ·ㅜ, 중모음 ㅔ·ㅚ·ㅓ·ㅗ, 저모음 ㅐ·ㅏ.

## 판정 기준: 헷갈리는 경계
<!-- 단계: 전체 -->
- 어미 vs 접사('쌓이다'), 명사형 어미 vs 파생 접사('-기', '-음'), 관형사 vs 형용사.
- 사동사 + '-어지다'는 이중 피동이 아니다. 피동사와 사동사가 같은 형태인 경우.
- '-되다' 형용사 파생.
- 형태소 경계: '국수'는 단일 형태소. 단일어 함정: '즐기다'. 접두사 판별: 암-, 늦-, 웃-.
- 뜻이 다르면 품사도 다르다는 착각: '한 30명'과 '한 교실'은 둘 다 관형사.
- '께서'는 가변어가 아니다.
- 형태가 같은 다른 단어: '수도꼭지를 트는'(틀다의 활용형) ↔ '길을 트다'.
- 단체 + '에서' = 주어.
- 어근 = 자립 가능한 것이라는 착각. 융합 합성어 = 뒤가 앞을 제한한다는 착각.
- 다의어인데 문형이 같은 쌍('돌다').
- 명사절 성분: '옳았음이' = 주어, '이르기 바란다' = 목적어.
- 학설이 갈리는 분석(직접 구성 성분이 둘로 나뉘는 단어)은 문항에 쓰지 않는다. 교과서·지도서 기준을 따른다.

## 문항 형식
<!-- 단계: 설계 -->
- 기본: **〈보기〉 개념·규정 조항 + 용례 적용**.
- 표준 발음법·맞춤법 조항을 용례와 대응시키기(표는 줄글로 풀어 〈보기〉에).
- '**모두 고르면 몇 개**'(진술 6~7개), a~f·ㄱ~ㅅ **있는 대로 고르기**, '~가 다른 하나는?'. 정답 2개 고르기를 내는 학교도 있다(시험지 파일은 정답 하나만 지원하니 '있는 대로 고르기' 조합형으로 바꿔 낸다).
- 표 빈칸, 매트릭스(실현 방식 × 수식 대상), 예/아니요 순서도, 학생 대화 판단.
- 중세·근대 원문 + 현대어 풀이 세트, 문학 작품을 문법 자료로 활용(시어의 표준 발음).
- 개념 지문 + 2~3문항 세트(지문형 문법).
- 횟수·순서·동화 여부·음운 개수를 **직접 세는** 문항, 체계표(모음 사각도·자음 체계표) 적용, 잘못된 발음의 원인 묻기.
- 단어: 형태소 개수와 단어 개수 비교, 단어 형성 도식, 사전 표제어 활용(어깨번호, 중심 의미, 뜻풀이별 반의어·유의어), 의미 관계, 새말의 직접 구성 성분(어미·접사 포함 여부), 접사의 적용 범위(형용사 어근 전용 '새-/시-' vs 색채어 어근 전반 '연-').
- 서술형 문법(발음 과정, 유형 이름 + 대분류, 간접 인용으로 바꾸기, 조건에 맞춰 문장 만들기, 오류 수정 + 이유)은 `guide.py 서술형`.

## 고난도 요인
<!-- 단계: 작성 -->
- **다단계 판단**: 활용 여부 → 변동 종류 → 표기 반영 여부 → 교체/탈락. 순서도의 다단계 분류에서 1단계를 건너뛰지 않게 한다.
- **음운 개수 증감 계산**, 변동 횟수('교체 한 번, 탈락 한 번'), 변동 순서(A → B, 첨가 후 교체).
- **짝 선지 한쪽만 틀리게**: 두 예를 한 선지에 묶고 하나만 틀리게 한다(축약 −1이 맞는 '입학'과 탈락이 없는 '열었다'를 짝). 학생이 실제로 가장 많이 걸리는 형식이다.
- **결론은 맞고 이유가 틀린 선지**.
- 사잇소리·사이시옷 조건을 어디에 귀속시키는가, 표준 발음법 조항을 엉뚱한 조항에 귀속시키기, '**다만**' 예외 조항, 틀린 발음 끼워 넣기.
- 관형절의 생략 성분(관계 관형절 vs 동격 관형절), 간접 인용의 상대 시제, 한정어('만', '모두', '다른'), 동작상, 서술어 자릿수와 필수적 부사어, 띄어쓰기 개수 세기.
- **한 선지에 조건 두 개 겹치기**: 의존 명사 앞 관형어 + 문형, 다의어 의미 차이 + 문형 차이, 자릿수가 같음 + 필수 성분 종류가 같음/다름.
- 안긴절의 존재 여부와 필수 성분 여부를 **따로** 판단하게 하기. 주어가 생략된 겹문장을 홑문장으로 판단하게 하기.
- 직접 구성 요소 층위 분석(볶음면, 싸움꾼, 눈웃음/비웃음), 대등·종속·융합 합성어가 의미에 따라 바뀌는 경우(밤낮, 찬밥), 통사적/비통사적 합성어 이진 부호(101101).
- **'모두 고른 것'**: 〈보기〉 ㄱ~ㅁ 중 틀린 것 하나만 빼는 정밀 판단.
- **〈조건〉 4개로 문장 만들기**: 밑줄 부분만, 같은 성분, 주성분·부속 성분·독립 성분 모두, 서로 다른 부속 성분 두 개.
- 재귀사 '자기'의 지시 대상: 후보가 둘이어도 맥락이 정하면 한정된다.
- '**각각**'이 들어간 선지는 한쪽만 성립해도 오답이다.

## 음운 함정
<!-- 단계: 작성 -->
- 표기에 반영되는지 여부, 비음화와 유음화 섞기, '밭이랑'·'옻이[오치]' 구개음화 착각.
- 이중 보기(교사 설명 + 사전 발음 정보)에서 한쪽 정보만 쓰게 하기.
- 조음 방법을 정의로만 쓴 선지, 모음 비교 선지 네 개가 방향을 하나씩 뒤집기.
- 예시 단어는 다른 변동이 끼지 않는 것으로 고른다(같이[가치]는 연음만의 예가 아니다).

## 중세 국어
<!-- 단계: 작성 -->
- **형식**: 원문(방점 포함) + 현대어 풀이. 현대어 풀이의 빈칸 ⓐ~ⓔ 채우기, 〈보기〉 개념(주격 조사 이형태, ㅎ 종성 체언, 부사격 조사)을 원문 예에 대응, 상자를 친 한 단어를 여러 층위로 분석(모음 조화, 전성 어미, 어두 자음군, 성조, 소실 자음), 중세 예와 현대에 흔적이 남은 단어 짝짓기(돌콰 ↔ 살코기), 형태가 같은 조사의 기능 구별(부사격 '이' vs 보격 '이'), 작품 정보 진술(창제 동기, 최초의 한글 작품).
- **함정**: 조건·높임 대상·개념 이름 중 **하나만** 바꾸기, 의미 변화('어엿비'를 '어여쁘게'로), 작품 정보 교체(한 문헌의 특징을 다른 문헌에), 형태와 기능 바꿔치기, 근대 표기 역추론, 향찰의 음차·훈차, 조사 없는 필수 부사어, 훈민정음 표기 원리('있는 대로'), ㆁ/ㅎ 종성, 재음소화, 탐구 자료 표.

| 항목 | 조건 |
|---|---|
| 주격 조사 | 자음 뒤 '이' / 'ㅣ'·반모음 'j' 이외의 모음 뒤 'ㅣ' / 'ㅣ'·'j' 뒤 '∅' |
| 관형격 조사 | 평칭 유정 체언 'ᄋᆡ/의'(모음 조화) / 무정 체언·존칭 유정 체언 'ㅅ' |
| 객체 높임 | 어간 말음 'ㄱ, ㅂ, ㅅ, ㅎ' 뒤 '-ᄉᆞᆸ-' / 'ㄷ, ㅈ, ㅊ' 뒤 '-ᄌᆞᆸ-' / 모음·유성 자음 뒤 '-ᅀᆞᆸ-' |

- 옛한글은 원문 그대로 조합형 자모로 쓴다. 기존 한글 파일에서 옮긴 옛한글이 한컴 전용 문자(사용자 정의 영역, PUA)로 들어 있으면 조합형 자모로 바꾼 뒤 쓴다(그대로 두면 다른 환경에서 깨진다). 고어 풀이가 갈리는 어휘는 현대어 풀이를 함께 주거나 풀이가 확정된 어휘만 쓴다.

## 맞춤법

- **조항 원문을 적용**하게 한다. 함정: 단서 조항 누락, 규정 이중 적용, 형태가 같은 말의 품사 오판.
- 맞춤법 세트에는 **사이시옷, 된소리 표기 조항, 준말 조항**을 넣는다.
- 자주 나오는 조항: 제1항, 형태소 밝혀 적기, 제5항, 제19항, 띄어쓰기, '-오/-요', 준말 제34~39항.
- 사이시옷 서술형은 순서도를 주고 '**단계 번호 + 최종 표기**'를 쓰게 한다.
