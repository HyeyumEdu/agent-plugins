# 막혔을 때

| 증상 | 원인 | 할 일 |
|---|---|---|
| 설치했는데 도구가 계속 안 보인다 | 앱이 설치 전 PATH를 쓰고 있다 | 앱을 완전히 종료 후 다시 연다. Claude Code는 `/mcp` → Reconnect |
| PowerShell이 설치 명령을 막는다, 보안 프로그램 경고 | 학교 PC의 실행 정책·보안 프로그램 | `winget install --id=astral-sh.uv -e`를 쓴다. 그래도 막히면 학교 전산 담당자에게 "uv(astral.sh) 설치 허용"을 요청하는 문장을 써 준다 |
| 처음 켤 때 시간이 오래 걸리거나 실패한다 | 파이썬과 부품을 인터넷에서 내려받는 중이거나 학교 방화벽이 막는다 | 1~2분 뒤 다시 연결한다. 계속 실패하면 다른 네트워크(예: 휴대폰 핫스팟)에서 한 번 켠다. 한 번 받아 두면 다음부터는 받아 둔 것을 쓴다 |
| "문서를 찾을 수 없다" | 허용된 폴더 밖의 파일이다 | 파일을 문서·바탕화면·다운로드 폴더로 옮긴다. 확장은 설정의 "추가로 허용할 폴더"에서 폴더를 더할 수 있다 |
| "파일이 손상됐거나 HWPX 형식이 아니라서 열 수 없다" | 도구 문제가 아니라 그 파일 문제다 | 한글에서 열어 HWPX(.hwpx)로 다시 저장한 파일을 쓴다. 한글에서도 안 열리면 원본을 다시 받는다 |
| `.hwp` 파일이 안 된다 | 구형 형식이다 | 한글에서 "다른 이름으로 저장 → HWPX(.hwpx)"로 저장한 파일을 쓴다 |
